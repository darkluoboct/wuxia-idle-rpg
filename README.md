# 金庸群侠：问道武林 · Wuxia Idle RPG

> 基于金庸武侠世界观的新国风**文字放置 RPG**（Idle RPG）设计与可运行前端 Demo。
> 核心规格：`开局无门派散人` + `1 主角 & 2 伙伴（三人行）` + `静态立绘 & 纯文字战斗表现` + `以《射雕》为起点，向《神雕》《倚天》《笑傲》《天龙》《侠客行》递进扩展`。

本项目包含两大部分：

| 目录 | 内容 |
| :--- | :--- |
| `docs/` | 12 册完整策划案：产品总纲、世界观、剧情库、数值模型、装备图鉴、门派机制、联网生态、前后端架构协议 |
| `frontend/` | 可独立运行的 Vue 3 Demo，内置本地模拟服务端（Mock Engine），**无需后端即可体验全功能** |

---

## 快速开始

```bash
cd frontend
pnpm install
pnpm dev          # http://localhost:5173
```

`frontend/.env.example` 默认 `VITE_USE_MOCK=true`，纯前端即可跑通完整玩法循环。若要接入真实后端，改为 `false` 并配置 `VITE_API_BASE_URL` / `VITE_WS_URL`。

其他命令：

```bash
pnpm build        # vue-tsc 类型检查 + vite 生产构建
pnpm preview      # 预览构建产物
```

## 玩法与已实现模块

五个主页签，对应完整核心循环：

| 页签 | 系统 | 说明 |
| :---: | :--- | :--- |
| **修行** | 打坐吐纳 | 离线挂机产出、境界冲穴进度、滚动文字日志 |
| **江湖** | 历练推进 | 章节节点、正邪支线抉择、`1 主 + 2 伙伴` 文字战报演武台 |
| **武库** | 阵容装配 | 内 / 外 / 轻 / 绝 四槽武学、装备穿戴、架势克制（刚猛 / 奇门 / 太极） |
| **门派** | 拜师晋升 | 五阶辈分考核、散人特权、叛师规则 |
| **市井** | 客栈鬼市 | 醉仙客栈请酒结交、子时鬼市鉴宝、全服唯一真品神兵流转 |

数值与战斗表现为**服务端权威**设计：客户端只负责渲染结构化战报（`RichLogStream`），战斗结算、掉落、唯一物品锁均在服务端完成 —— Demo 中以 `mockEngine.ts` 模拟该契约。

## 技术栈

**前端**
- Vue 3.5 `<script setup>` + TypeScript 5.7
- Vite 6 · Pinia 3 · Tailwind CSS 4 · lucide-vue-next 图标
- 宣纸 / 玄墨双主题，水墨卷轴响应式布局，固定逻辑分辨率（720p / 810p / 900p）自动缩放

**后端（设计蓝图，见 `docs/11`）**
- 无轮询惰性离线结算 · 确定性战斗引擎 · 唯一真品神兵锁 · 和平 / 纷争 PK 区校验
- PostgreSQL / MySQL + Redis，REST + WebSocket 接口与战报 JSON 契约
