# 金庸群侠：问道武林 · Wuxia Idle RPG

> 基于金庸武侠世界观的新国风**文字放置 RPG**，提供本地试玩与首轮联机。
> 核心规格：`开局无门派散人` + `1 主角 & 2 伙伴（三人行）` + `静态立绘 & 纯文字战斗表现` + `以《射雕》为起点，向《神雕》《倚天》《笑傲》《天龙》《侠客行》递进扩展`。

| 目录 | 内容 |
| :--- | :--- |
| `docs/` | 19 册策划案、伙伴获取与抽卡专题 |
| `frontend/` | Vue 游戏客户端与本地试玩 |
| `server/` | Fastify 游戏服务、PostgreSQL 迁移与 WebSocket 房间 |
| `shared/` | 前后端共用的装备配置、角色模板、战斗规则与通信类型 |
| `scripts/` | 第一卷历练数据校验 |

## 本机联机

准备 Node.js 24.8 或更新版本、pnpm 和一个 PostgreSQL 数据库。参照 `server/.env.example` 创建 `server/.env.local`，填入 `DATABASE_URL`。`APP_ORIGIN` 使用浏览器访问的地址，默认 `http://localhost:5173`。

在第一个终端启动游戏服务。

```bash
cd server
pnpm install
pnpm migrate
pnpm start
```

在第二个终端启动客户端。

```bash
cd frontend
pnpm install
pnpm dev:online --host localhost --strictPort
```

在普通窗口和无痕窗口分别注册账号并创角，创角时选一个家世（将门、渔家、杏林、玄门，见 `docs/17` §七）。新角色与本地「新游戏」同一套开局：Lv.1、300 元宝、佩青钢长剑，家世里的那位家人已经在队里。第一次进江湖先过序章（和家人在破庙救下忘机客，打主线 1-1），之后客栈、地图与丹房、结缘、鬼市、门派、华山论剑、结义副本、襄阳守卫战等玩法随主线、历练与境界依次开放，每开放一项弹一张剧情卡（见 `docs/17` §六）；老角色不受影响。右栏《江湖行历》两卷 18 阶，由剧情人物带路；「每日江湖事」做完四件可领元宝。两人出生在嘉兴烟雨楼外，从右侧「附近」进入「同图聊天」。退出重新登录后进度都在。

市井的醉仙客栈里可以结缘抽卡、为伙伴觉醒、用故人重逢令补回错过的伙伴，结识洪七公后还能为他做十道绝味。子时鬼市每天有一场全服压轴暗拍：出价填心理价，有人来压鬼市按每口替你跟到心理价为止，不必守在落槌前；被压过的一方元宝立即退还并收到提醒，21:00 落槌后由领先者按成交价领取、多冻的退还，成交价的三成作红封，子时分给当天领过每日江湖事的侠客。这些都由服务端出结果并记账：每笔元宝写入 `ingot_ledger`，每一抽写入 `gacha_log`。

鬼市里还有蒙面摊位：Lv.10 以上的侠客可以把草药和武学残页标价摆出来，别的侠客用纹银买走，买卖双方都只见代号。一个窗口摆摊、另一个窗口买下，摊主会立刻收到提醒，纹银扣一成后入账；没卖掉的 24 小时后退回。

市井的兵器谱记着全服唯一的真·绿玉打狗棒在谁手里。第一位通过丐帮终考的侠客得棒；每周日君山开擂，通过终考的侠客每天可上擂三次，胜者当场执棒并接着守擂。执棒者连续 72 小时没有任何操作或叛出丐帮，打狗棒由传功长老收回代守，这时任何一天都能上擂。易主时全服在线的侠客都会在传闻频道看到。

两位侠客在线且同处一张和平地图时，可以在「附近」点「邀请共修」。对方在 60 秒内同意后，共修持续 4 小时，双方真气收益提高 15%。断线继续计时，任一方换图或点「结束共修」时，两人同时结束。

三位侠客可以在「附近」发起组队。入队后到「江湖 → 结义副本」，三人各点「准备」，再由队长挑战少室山金刚伏魔圈。每人按自己的通关次数领奖，第一胜给岳武穆遗书，第二胜给笑傲江湖琴箫谱。胜场和奖励会写入存档。同伴不在线时，可以在同一页挑两位侠客登记的结义镜像同闯，奖励只发给自己；打过副本会自动登记自己的镜像，也可以手动按当前配装登记。

共修可以给不在线的侠客留帖，一天内对方上线、仍在此地就能应邀；结义镜像被借去打赢，主人得助战真气。收功时弹出「江湖邸报」，一次列清离线期间的修行、巡历、襄阳代打、被劫、鬼市与助战。

劫镖与追捕不必对方在线：停在同一张地图就能出手，对方不在时由他的镜像应战（「附近」里另列不在线的押镖与被通缉侠客，悬赏榜接令后能看到目标停在哪张地图），对方下次收功时在江湖纪事里看到战果。切磋仍要双方同图在线。打坐与巡历最多累计 24 小时未领收益，巡历宝箱的元宝按周封顶（见 `docs/21_挂机友好的异步玩法.md`）。

每周一场，周一 00:00 到下周一 00:00（北京时间），到「江湖 → 襄阳守城」各守一门：东门、北门或水路粮道。军令每 8 小时回一道、最多攒三道，打掉的敌军气血折成战功，全门战功攒够就击退一波，共八波。出战或「值守此门」后，下线时军令攒满就由你的镜像替你出战，收兵时把余下的打完；周三、周日 20:00 起擂鼓一个时辰，亲自出战战功加五成。收兵后收功时顺带领元宝、玄铁、淬火石与功法残页，随时可以上城演练（见 `docs/20_襄阳守卫战.md`）。

在「武库 → 武学」换上已学武功，就能看到升重花费和下一重效果。以《越女剑法》为例，升重后可在主线和少室山战报里看到新威力带来的伤害变化。

联机客户端通过同域 `/api` 和 `/ws` 连接服务。开发环境的 Vite 代理指向 `127.0.0.1:8080`。部署时用 HTTPS 提供 `pnpm build:online` 生成的前端，并将同域的 `/api` 和 `/ws` 代理到游戏服务。

## 本地试玩与检查

```bash
cd frontend
pnpm dev           # 本地试玩
pnpm lint          # 检查前端、后端与共享代码
pnpm test          # 数据、剧情、战斗、抽卡、存档与组件测试
pnpm build         # 类型检查并构建本地试玩客户端
pnpm build:online  # 类型检查并构建联机客户端
```

从登录页进入试玩并选择角色后，可以从 Lv.1 开始新游戏，或进入 Lv.32 演武模式。试玩进度自动保存到浏览器，开局时可继续最近游玩的角色。设置 `VITE_LOCAL_SAVE=false` 可关闭试玩存档。开发时使用 `?mode=new` 或 `?mode=demo` 可直接进入对应开局。

在 `server/` 下运行 `pnpm check` 检查类型。设置 `GAME_TEST_DATABASE_URL` 指向专用 PostgreSQL 测试库后，运行 `pnpm test:game` 验证联机接口。仓库根目录可运行 `node scripts/validate_trial_data.ts` 校验 30 关历练配置。

在 `frontend/` 下运行 `pnpm exec playwright install chromium` 安装测试浏览器。执行 `pnpm build` 后运行 `pnpm test:e2e`，可验证试玩、五个页签和读档。设置 `WUXIA_E2E_DATABASE_URL` 指向专用测试库后，同一命令会启动游戏服务，并验证双账号注册、创角、同图聊天和恢复角色。开发时可以用 `pnpm format <文件>` 格式化指定文件。

GitHub Actions 在每次拉取请求和推送到 `main` 时运行代码检查、两种前端构建、历练数据校验及前后端测试。仓库可将 `checks` 设为 `main` 的必过检查。

## 玩法与已实现模块

五个主页签，对应完整核心循环：

| 页签 | 系统 | 说明 |
| :---: | :--- | :--- |
| **修行** | 打坐吐纳 | 离线挂机产出、境界冲穴进度、滚动文字日志 |
| **江湖** | 历练推进 | 三十关历练与巡历挂机、16 个试玩主线节点、13 个支线奇遇、`1 主 + 2 伙伴` 文字战报演武台 |
| **武库** | 阵容装配 | 四槽武学、八槽装备、经脉冲穴、架势克制、双人和收集羁绊 |
| **门派** | 拜师晋升 | 七个试玩门派、五阶辈分考核与授武、散人特权、叛师规则 |
| **市井** | 客栈鬼市 | 醉仙楼结缘、客栈结交、故人寻访、十道绝味、百草丹房、子时鬼市 |

### 伙伴怎么来（详见 `docs/专题_伙伴获取与抽卡系统设计.md`）

25 位伙伴分三条路线：

| 路线 | 规则 | 例 |
| :--- | :--- | :--- |
| 剧情送 | 主线 / 支线到点直接入队，品质最高紫品 | 柯镇恶、穆念慈、马钰、少年郭靖 |
| 好感线 | 剧情只负责结识，在客栈养到好感 100 入队；橙品为「橙·下」资质 | 丘处机、瑛姑；洪七公须先呈齐「十道绝味」 |
| 抽卡 | 客栈「醉仙楼·结缘」获得 | 一灯大师、王重阳、哲别 |

- **形态与觉醒**：郭靖 / 黄蓉以紫品少年形态入队，洪七公等四位大侠以橙·下入队，好感 600 + 伙伴信物可觉醒为橙 / 红品。
- **醉仙楼·结缘**：单抽 100 / 十连 950 元宝；神品 0.8%、绝品 6%、上品 25%；70 抽起软保底、90 抽硬保底、十连保底上品；界面内含完整概率公示（含保底的综合神品出率约 1.8%）。求签式揭晓动画。
- **元宝**：首通、突破、行历、奇遇、集齐羁绊、门派晋升、每日江湖事、巡历宝箱、华山论剑、门派演武、结义副本与襄阳守卫战都会产出，第一卷免费约 1 万（见 `docs/19_元宝获取与经济循环.md`）。元宝不卖真气和挂机时间。
- **错过的伙伴**：免费的「故人寻访」约 30 天（每日线索有上限）；或花 150 元宝用「故人重逢令」直接重逢。


联机版的全部玩法由服务端结算。本地试玩只是测试入口，调用 `shared/` 里的同一份规则，存档放在浏览器。

## 技术栈

**前端**
- Vue 3.5 `<script setup>` + TypeScript 5.7
- Vite 6 · Pinia 3 · Tailwind CSS 4 · lucide-vue-next 图标 · Vitest 3
- 玄墨描金 / 宋宣双主题；嘉兴、终南、大漠、黑沼实景插画，嘉兴随时辰换景。宽屏显示人物、场景、江湖三栏，平板用右抽屉，手机用底部导航和双抽屉。

**后端**

- Node.js 24 · TypeScript 5.9 · Fastify 5 · PostgreSQL。
- HTTP 接口处理角色存档和游戏结算，WebSocket 同步同图玩家、聊天与组队。接口与存档流程见[联网后端实施设计](docs/12_联网后端实施设计.md)。
