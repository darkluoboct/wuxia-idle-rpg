# 金庸群侠：问道武林 · Wuxia Idle RPG

> 基于金庸武侠世界观的新国风**文字放置 RPG**，提供本地试玩与首轮联机。
> 核心规格：`开局无门派散人` + `1 主角 & 2 伙伴（三人行）` + `静态立绘 & 纯文字战斗表现` + `以《射雕》为起点，向《神雕》《倚天》《笑傲》《天龙》《侠客行》递进扩展`。

| 目录 | 内容 |
| :--- | :--- |
| `docs/` | 18 册策划案、伙伴获取与抽卡专题 |
| `frontend/` | Vue 游戏客户端与本地试玩 |
| `server/` | Fastify 游戏服务、PostgreSQL 迁移与 WebSocket 房间 |
| `shared/` | 前后端共用的装备配置、角色模板、战斗规则与通信类型 |

## 本机联机

准备 Node.js 24.8 或更新版本、pnpm 和一个 PostgreSQL 数据库。参照 `server/.env.example` 创建 `server/.env.local`，填入 `DATABASE_URL`。`APP_ORIGIN` 使用浏览器访问的地址，默认 `http://localhost:5173`。

在第一个终端启动游戏服务。

```bash
cd server
pnpm install
pnpm migrate
pnpm start
```

在第二个终端启动客户端。

```bash
cd frontend
pnpm install
pnpm dev:online --host localhost --strictPort
```

在普通窗口和无痕窗口分别注册账号并创角。两人出生在嘉兴烟雨楼外，从右侧「附近」进入「同图聊天」。在「武库 → 装备」换上青钢长剑，再到「江湖 → 射雕主线」挑战赵王府。首胜拿到青布腰带，退出重新登录后可继续换装和闯关。

两位侠客在线且同处一张和平地图时，可以在「附近」点「邀请共修」。对方在 60 秒内同意后，共修持续 4 小时，双方真气收益提高 15%。断线继续计时，任一方换图或点「结束共修」时，两人同时结束。

三位侠客可以在「附近」发起组队。入队后到「江湖 → 结义副本」，三人各点「准备」，再由队长挑战少室山金刚伏魔圈。每人按自己的通关次数领奖，第一胜给岳武穆遗书，第二胜给笑傲江湖琴箫谱。胜场和奖励会写入存档。

在「武库 → 武学」换上已学武功，就能看到升重花费和下一重效果。以《越女剑法》为例，升重后可在主线和少室山战报里看到新威力带来的伤害变化。

联机客户端通过同域 `/api` 和 `/ws` 连接服务。开发环境的 Vite 代理指向 `127.0.0.1:8080`。部署时用 HTTPS 提供 `pnpm build:online` 生成的前端，并将同域的 `/api` 和 `/ws` 代理到游戏服务。

## 本地试玩与检查

```bash
cd frontend
pnpm dev           # 本地试玩
pnpm test          # 数据、剧情、战斗、抽卡与存档测试
pnpm build         # 类型检查并构建本地试玩客户端
pnpm build:online  # 类型检查并构建联机客户端
```

从登录页进入试玩并选择角色后，可以从 Lv.1 开始新游戏，或进入 Lv.32 演武模式。试玩进度自动保存到浏览器，开局时可继续最近游玩的角色。设置 `VITE_LOCAL_SAVE=false` 可关闭试玩存档。开发时使用 `?mode=new` 或 `?mode=demo` 可直接进入对应开局。

后端类型检查在 `server/` 下运行 `pnpm check`。

## 玩法与已实现模块

五个主页签，对应完整核心循环：

| 页签 | 系统 | 说明 |
| :---: | :--- | :--- |
| **修行** | 打坐吐纳 | 离线挂机产出、境界冲穴进度、滚动文字日志 |
| **江湖** | 历练推进 | 三十关历练与巡历挂机、16 个试玩主线节点、13 个支线奇遇、`1 主 + 2 伙伴` 文字战报演武台 |
| **武库** | 阵容装配 | 四槽武学、八槽装备、经脉冲穴、架势克制、双人和收集羁绊 |
| **门派** | 拜师晋升 | 七个试玩门派、五阶辈分考核与授武、散人特权、叛师规则 |
| **市井** | 客栈鬼市 | 醉仙楼结缘、客栈结交、故人寻访、十道绝味、百草丹房、子时鬼市 |

### 伙伴怎么来（详见 `docs/12_伙伴获取与抽卡系统设计.md`）

25 位伙伴分三条路线：

| 路线 | 规则 | 例 |
| :--- | :--- | :--- |
| 剧情送 | 主线 / 支线到点直接入队，品质最高紫品 | 柯镇恶、穆念慈、马钰、少年郭靖 |
| 好感线 | 剧情只负责结识，在客栈养到好感 100 入队；橙品为「橙·下」资质 | 丘处机、瑛姑；洪七公须先呈齐「十道绝味」 |
| 抽卡 | 客栈「醉仙楼·结缘」获得 | 一灯大师、王重阳、哲别 |

- **形态与觉醒**：郭靖 / 黄蓉以紫品少年形态入队，洪七公等四位大侠以橙·下入队，好感 600 + 伙伴信物可觉醒为橙 / 红品。
- **醉仙楼·结缘**：单抽 100 / 十连 950 元宝；神品 1.5%、绝品 8%、上品 30%；60 抽起软保底、80 抽硬保底、十连保底上品；界面内含完整概率公示（含保底的综合神品出率约 2.4%）。求签式揭晓动画。
- **错过的伙伴**：免费的「故人寻访」约 30 天（每日线索有上限）；或花 150 元宝用「故人重逢令」直接重逢。


联机的战斗、存档、掉落和共修由服务端结算。扩展主线、抽卡和伙伴养成在本地试玩中使用模拟引擎及浏览器存档。

## 技术栈

**前端**
- Vue 3.5 `<script setup>` + TypeScript 5.7
- Vite 6 · Pinia 3 · Tailwind CSS 4 · lucide-vue-next 图标 · Vitest 3
- 玄墨描金 / 宋宣双主题；嘉兴、终南、大漠、黑沼实景插画，嘉兴随时辰换景。宽屏显示人物、场景、江湖三栏，平板用右抽屉，手机用底部导航和双抽屉。

**后端（设计蓝图，见 `docs/11`）**
- 无轮询惰性离线结算 · 确定性战斗引擎 · 唯一真品神兵锁 · 和平 / 纷争 PK 区校验
- PostgreSQL / MySQL + Redis，REST + WebSocket 接口与战报 JSON 契约
