# 22 · 运营管理后台（已实装）

> 口径：只在联机版里有。后台账号与玩家账号分开，后台的每一次登录与写操作都记审计日志。

---

## 一、入口与首个超管

| 项目 | 说明 |
| :--- | :--- |
| 页面 | 与游戏同域名的 `/admin.html`（前端构建同时产出 `dist/admin.html`）。开发时 `pnpm dev` 后打开 `http://localhost:5173/admin.html` |
| 接口 | `/api/admin/*`，与游戏服务同一进程 |
| 首个超管 | 只能用命令行建，不留默认密码：`cd server && ADMIN_PASSWORD='至少12位' npm run admin:create -- <账号> SUPER`。之后的账号由超管在后台建 |
| 会话 | 登录后 12 小时有效；Cookie `wuxia_admin` 只发往 `/api/admin`，`HttpOnly`、`SameSite=Strict`，线上 `Secure`。登录每个来访 IP 每分钟最多 10 次，IP 记进审计（要求反向代理传 `X-Forwarded-For`，见 README） |

**上线建议**：在反向代理上把 `/admin.html` 与 `/api/admin/` 限制到公司网络或 VPN（IP 白名单），后台密码不要与别处共用。目前没有二次验证。

## 二、权限

| 权限 | 能做什么 |
| :--- | :--- |
| 客服 `SUPPORT` | 看总览、查侠客与流水、看邮件与公告、看审计与聊天；禁言、解除禁言、踢下线、删除违规发言 |
| 运营 `OPERATOR` | 客服的全部，再加封号、解封、重置玩家密码、调整玩家资产、恢复已删除的角色、发系统邮件与撤回、发公告与撤下、上架与修改商品、开与结束倍率活动、改聊天屏蔽词 |
| 超管 `SUPER` | 运营的全部，再加管理后台账号：建号、改权限、停用或启用、重设密码。不能给自己降权或停用自己 |

规则在 `shared/admin.ts`（`ADMIN_PERMISSIONS`），前后端共用；界面上没权限的按钮置灰，服务端同样拦（`403 ADMIN_FORBIDDEN`）。

## 三、功能

### 总览
在线人数、侠客总数、今日新增、今日活跃（今天收过功或有过任何操作）、封禁中、今日结缘抽数，以及今日元宝流水按来源合计（产出与消耗分开）。「今日」按北京时间零点起算，每半分钟刷新。

### 报表
- **近 14 天按日**：新增、活跃、元宝产出与消耗、结缘抽数、商行元宝收入、最高在线。新增、活跃、元宝消耗、最高在线各画一张柱状图，悬停看当天数值，下面是明细表。
- **新侠客留存**：按建角日分组，次日、第 3 日、第 7 日还来（当天有过任何操作）的人数与比例；还没到那天的记「—」。
- **分布**：等级（每 10 级一档）、境界、门派、所在地图。
- 活跃按侠客当天有没有写操作记（`player_activity_days`），最高在线每 5 分钟取一个点（`online_samples`，留 35 天），两者都从这次更新起才有数据。

### 倍率活动
- 三类：**挂机真气**、**挂机纹银**（打坐与巡历挂机的收益）、**巡历掉落**（小怪掉件几率，封顶必掉）。加成 +10% 至 +400%（五倍），持续 1 小时至 30 天，可预约 30 天内开始。
- 按时段折算：只有落在活动时段里的挂机时长加成，下线挂着也算；与共修加成相乘。同时段同类活动不叠加，取最高。巡历掉落按这段巡历里活动时长的占比折算。
- **不能补到过去**：开始时刻最早为此刻。**提前结束**只停在此刻，已累计的加成不收回；还没开始的直接取消。
- 开、结束后立刻推给全服在线侠客（`RATE_BOOSTS`）。游戏的修行页列出进行中的活动，时薪与可领收益按活动折算。
- 结缘抽卡的概率不在可调之列（概率要公示）。

### 运营商店（游戏里叫「江湖商行」）
- 商品内容与邮件附件同形：纹银、真气、装备、武学残页、丹药，**不卖元宝**。用元宝或纹银买。
- 可设：限购（每人总计 / 每日 / 每周几次；每日在子时 23:00 换日，每周在周六 20:00 换周，与每日江湖事、门派演武同步）、全服库存、开售时刻、上架时长、排序（大的在前）。上架后可改价、改库存、下架与重新上架。
- 后台列出每件商品的已售、收入与买家数。元宝付款记流水 `shop`。
- 游戏的「市井 → 江湖商行」列出在售商品，显示限购进度、全服剩余与下架时刻；买到即入账。单机试玩没有运营，不显示这个页签。

### 已删除的角色
「玩家」页底部列出 30 天内删除的角色，核实身份后可恢复，条件见 24 册第三节。

### 聊天监控与屏蔽词
见 23 册第三节：按频道或侠客查聊天、删除违规发言、维护屏蔽词；私聊只在按侠客查时列出。

### 调整玩家资产
在「玩家」详情里给某位侠客加或扣元宝、纹银、真气（每项一次最多 ±1 万元宝、±1000 万纹银、±1 亿真气），必须写原因；扣完不能为负。元宝记流水 `admin`，审计记下增减、调整后余额与原因。他在线的话页面会自动补读档案。

### 玩家
- **查找**：按昵称、账号或角色 ID 模糊查，不填列最近建角的 50 位。
- **详情**：账号、等级境界、所在、门派、家世、元宝纹银真气、装备武学伙伴数、建角与上次收功时刻；最近 50 笔元宝流水、最近 20 抽结缘。
- **处置**：

| 操作 | 效果 |
| :--- | :--- |
| 禁言 | 1 小时到永久；同图聊天被拒（`CHAT_MUTED`），其他照常 |
| 踢下线 | 删掉他的全部会话、断开在线连接，需重新登录 |
| 封号 | 1 小时到永久，必须写理由；立刻踢下线，登录与每次请求都拒（`403 ACCOUNT_BANNED`），理由会显示给玩家 |
| 重置密码 | 生成 12 位临时密码，只在这次回执里显示一次，审计不记；他的全部设备下线。用于玩家找回账号，请先核实身份 |

### 系统邮件
- 发给指定侠客（在「玩家」页点「给他发信」自动填角色 ID），或全服。全服信可勾「只发给发信时已建角的侠客」，用于维护补偿；不勾则之后新建角的侠客也能领，用于开服福利。
- 附件：元宝（≤ 10,000）、纹银（≤ 1,000 万）、真气（≤ 1 亿）、装备（≤ 10 件，已拥有的不重复发）、武学残页（每门 ≤ 100 张）、冲穴与突破丹药（每种 ≤ 100 枚）。上限防手滑，在 `MAIL_LIMITS`。
- 有效期 1~90 天，默认 30 天。可以撤回：已领的不受影响，没领的再也领不到。
- 发出时在线的侠客立刻收到提示（`MAIL_NEW`）；游戏顶栏的信封显示未领封数，领一次即到账。元宝记流水 `mail`，`ref` 为 `mail:信件`，每人每封只入账一次。

### 全服公告
写 120 字内的公告，可设开始时刻（不填为立即）与持续时长（1 小时到 7 天）。生效时在线的侠客立刻弹出提示并写进江湖纪事，之后上线的在连上时看到，期间江湖快报滚动显示。可提前撤下。

### 审计日志
倒序列出后台的登录、处置、发信与撤回、发公告与撤下、调整资产、上架与修改商品、开与结束倍率活动、建号与改号，含操作人、对象与详情，每页 50 条。

## 四、实现

- **规则与数据形状**：`shared/admin.ts`（权限、附件校验与文字、后台 DTO）；玩家侧的 `MailDTO`、`AnnouncementDTO` 在 `shared/protocol.ts`。
- **服务端**：`server/src/admin.ts`（登录、总览、玩家处置、邮件、公告、审计、后台账号）、`server/src/adminOps.ts`（报表、倍率活动、商店、调整资产）、`server/src/rates.ts`（倍率活动缓存，每次操作前确认够新，后台增改后立刻重读）、`server/src/adminCreate.ts`（命令行建号）；封号在 `server/src/auth.ts` 的登录与会话校验里拦，禁言在 `server/src/rooms.ts` 的同图聊天里拦；玩家领信与公告在 `server/src/game.ts`（`GET /api/v1/mail`、`POST /api/v1/mail` 的 `claim`、`GET /api/v1/announcements`）。
- **倍率与商店的规则**：挂机按时段折算在 `shared/player.ts`（`idleQiNumerator` 带活动段、`averageBoostPct`），巡历掉落在 `shared/trialStages.ts`（`rollTrialDrop` 的 `dropPct`）；商店接口 `GET /api/v1/shop`、`POST /api/v1/shop` 在 `server/src/game.ts`，邮件与商店共用同一段发放。
- **数据**：`server/migrations/022_admin_ops.sql`：`rate_boosts`、`shop_goods`、`shop_purchases`、`player_activity_days`、`online_samples`。`server/migrations/021_admin.sql`：`admin_accounts`、`admin_sessions`、`admin_audit`、`mails`、`mail_claims`、`announcements`；`accounts` 加 `banned_until`、`ban_reason`，`players` 加 `muted_until`、`created_at`（老角色记为迁移时刻）。
- **后台界面**：`frontend/admin.html` 与 `frontend/src/admin/`（独立的素净界面，跟随系统深浅色）。
- **游戏界面**：顶栏信封与 `frontend/src/components/Mailbox.vue`；公告进江湖快报与提示条（`frontend/src/stores/world.ts`）；江湖商行 `frontend/src/components/ShopPanel.vue`；修行页的活动提示在 `CultivateConsole.vue`。
