# 21 · 挂机友好的异步玩法（已实装）

> 口径：联机为准，本地试玩调用同一份规则。本册记录为「不要求同一时段在线」所做的改动，各玩法的细则仍在各自册子里，有出入处以本册为准。

---

## 一、原则

这是挂机游戏，侠客不会在同一时段上线。凡是挂机玩家拿不到、或要和别人约好时间才拿得到的东西，都要改。

1. **能不能参与，不看此刻在不在线**。在线只影响打法：挑时机、换配装、看战报。
2. **需要别人参与的玩法，用镜像代替真人在场**。镜像冻结某一刻的境界、属性、配装与同行侠客，不带丹药（`shared/mirror.ts`，华山论剑、门派演武、藏经阁值守、襄阳值守、结义镜像、劫镖与追捕共用）。
3. **次数可攒、窗口至少一天**；错过结算时刻的奖励在下次上线时补发。
4. **日常可以有，但离线几天不应成倍损失**。

## 二、改了什么

| 玩法 | 原来 | 现在 | 细则 |
| :--- | :--- | :--- | :--- |
| 襄阳守卫战 | 周三、周日 20:00 开半个时辰，五道军令当场打完 | 每周一场整周打；军令每 8 小时回一道可攒三道；下线由镜像值守代打；20:00 改为擂鼓加功；收功顺带领赏 | 20 册 |
| 鬼市暗拍 | 落槌前 5 分钟有人出价就顺延，守到最后的人赢 | 出价填心理价，鬼市逐口代为跟价；落槌按成交价结算 | 19 册 §六 |
| 暗拍红封签 | 当日 21:00 前领每日江湖事才有 | 当日什么时辰领都算，子时开签 | 19 册 §六 |
| 结义副本 | 三人同时在线、同图、各点准备 | 照旧可以组队；同伴不在线时，可独自带两位侠客的**结义镜像**同闯 | 本册 §三 |
| 劫镖、追捕 | 双方都要在线、同图；对方下线就安全 | 同在一张地图即可，对方不在线由**他的镜像应战**，战果在他收功时告知 | 本册 §四 |
| 共修 | 双方在线、同图，一分钟内答复 | 对方不在线也能**留帖**，一天内有效；应邀只要两人停在同一张和平地图 | 本册 §五 |
| 回归 | 离线期间的事散在各处的纪事里 | 收功时弹出**江湖邸报**，一次列清 | 本册 §六 |
| 打坐与巡历 | 最多累计 12 小时未领 | 最多累计 **24 小时**，一天上线一次不吃亏 | 12 册、14 册 |
| 巡历宝箱元宝 | 每日最多 30，按领取那天算 | **每周最多 210**（同门派演武的周），隔几天上线一次也不吃亏 | 19 册 |

**仍要同时在线的**：切磋（社交本来就是即时的）、三人真人组队（可改用结义镜像）。

## 三、结义镜像

| 项目 | 规则 |
| :--- | :--- |
| 登记 | 打过一次三人副本（真人组队或借镜像）就按当时配装登记自己的结义镜像；也可以在「结义副本」页「登记我的结义镜像」或「按当前配装更新」。每人一份，覆盖更新 |
| 挑人 | 不在队伍里时，可从名单里挑两位不同的侠客（不含自己）。名单同门在前、等级相近在前，列十二位 |
| 同闯 | 自己加两份镜像对阵所选副本，与三人真人组队同一套战斗；不必同图 |
| 奖励 | 只发给自己，与真人组队相同：按自己的通关次数给秘宝、真气、纹银，每周首胜元宝 50 |
| 助战 | 镜像被借去同闯并打赢，主人记助战真气（该副本真气的两成，少室山为 3,700），每天最多记三次；主人下次收功时到账，写进江湖邸报 |
| 本地试玩 | 没有别的侠客，由乔北冥、清风道长两份镜像同闯少室山 |

- **联机**：`GET /api/v1/raid/mirrors`（自己是否登记、可借名单）；`POST /api/v1/raid/mirror`（登记或更新）；`POST /api/v1/raid/start` 传 `{ raidId, mirrorIds: [两位侠客] }` 即借镜像同闯，传 `{ teamId, revision }` 仍是真人组队。错误码：`INVALID_RAID_MIRROR`（不是两位不同的他人）、`RAID_MIRROR_MISSING`（镜像已不在）、`RAID_IN_TEAM`（在队伍里先离队）、`INVALID_RAID`。
- **数据**：`server/migrations/019_raid_mirrors.sql`，`raid_mirrors` 每人一行；`020_raid_mirror_lends.sql` 记待领的助战次数与真气、当日已记次数。规则在 `shared/mirror.ts`（`RAID_LEND`）。
- **界面**：`frontend/src/components/RaidLobbyPanel.vue`「借镜像结义」。

## 四、劫镖与追捕不必对方在线

| 项目 | 规则 |
| :--- | :--- |
| 条件 | 与对方停在同一张地图（按存档里的所在地，不看是否在线），自己不在赶路途中；劫镖仍限纷争区、对方正押着没被劫过的镖车；追捕仍要先接令 |
| 应战 | 对方同图在线：照旧用他当下的配装，用掉的丹药照扣。不在线：用他此刻的镜像应战，不带丹药，战报标题带「镜像应战」 |
| 结果 | 与在线时相同：劫镖得手分走三成镖银、镖车记为已劫；追捕得手结案、清除通缉 |
| 告知 | 对方不在线时，战果记进他的存档（最多十条），他下次收功时写进江湖纪事后清空：被劫走多少镖银、镜像是否守住、通缉是否了结 |
| 找到人 | 「附近侠客」在同图在线名单下另列「不在线、停在本图」的押镖与被通缉侠客；悬赏榜接令后显示目标停留的地图与是否在线 |

- **联机**：`GET /api/v1/map/absent` 列本图不在线、可劫镖或追捕的侠客（每图最多二十位）；`POST /api/v1/duel` 的 `ambush`、`pursue` 不再要求双方在线；悬赏榜条目接令后带 `mapId` 与 `online`；收功结果 `defenseNotices` 列出下线期间的战果。切磋（`invite` / `accept`）仍要双方同图在线。
- **本地试玩**：附近侠客都是模拟的在场侠客，规则不变。

## 五、共修留帖

| 项目 | 规则 |
| :--- | :--- |
| 邀请 | 两人停在同一张和平地图即可（按存档里的所在地）。对方在线：一分钟内答复；对方不在线：算留帖，一天内有效 |
| 应邀 | 应邀时两人仍停在那张地图、都没在共修即可，不必同时在线；开始后照旧共修 4 小时、真气 +15% |
| 撤回 | 发帖人可以「撤回邀请」，再邀别人；任一方离开那张地图，邀请作废 |
| 找到人 | 和平地图的「附近侠客」另列停在本图、不在线的侠客（最近上线的在前），可「留帖共修」 |

- **联机**：`POST /api/v1/map/co-cultivate` 新增 `cancel`（`invitationId`）；`invite` / `accept` 不再要求在线。`GET /api/v1/map/absent` 在和平地图列出所有停在本图的不在线侠客。

## 六、江湖邸报

收功时，服务端汇总「上次收功以来」你不在场时发生的事，前端弹窗一次列清。离开超过一个时辰（两小时），或期间有事发生，就弹出来。

| 段落 | 内容 |
| :--- | :--- |
| 修行 | 本次领到的真气与纹银，超过 24 小时注明按 24 小时计 |
| 巡历 | 打了几场、其中精英几场与玄铁、淬火石，掉落的装备，秘境宝箱的纹银与元宝 |
| 襄阳 | 值守镜像代打的次数与战功，顺带领到的论功封赏 |
| 镖车与通缉 | 不在线时被劫镖、被追捕的战果 |
| 鬼市 | 摊位卖出的份数与纹银，暗拍红封 |
| 结义 | 结义镜像随人破阵的次数与助战真气（此时到账） |
| 门派、杂事 | 门派演武元宝、故人寻访线索、十道绝味食材 |

- **联机**：收功结果 `away`（`AwayReportDTO`）给出起算时刻与襄阳代打、摊位卖出、红封、助战；修行、巡历、封赏、被劫通知仍在原有字段。起算时刻记在存档的 `lastReportAt`，每次收功更新。
- **本地试玩**：同一个弹窗，由本地的修行、巡历、襄阳代打与封赏拼成。
- **界面**：`frontend/src/components/AwayReport.vue`。

## 七、对节奏的影响

- **巡历进度**：第一卷 16~30 关共约 700 小时。原先上限 12 小时，每天只上线一次的侠客约两个月打完，每天上线两次的侠客约一个月；放宽到 24 小时后，每天上线一次也是约一个月（14 册）。**不改各关所需时长**：时长翻倍会让每关挂出的真气、装备掉落也翻倍，第一卷的数值要整体重调；现在每关的产出不变，只是日历上快了。
- **元宝**：巡历宝箱每周上限 210 等于原来每天 30 的七天之和，总量不变，只是不再按天作废。襄阳每周 40 与原来两场各 20 持平。结义副本首胜每周 50 不变，只是不再需要凑齐三人。
