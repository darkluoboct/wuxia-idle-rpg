# 26 · 开始与停止挂机（已实装）

> 口径：原先角色一建好，打坐与巡历就自动累计，玩家没点过什么就已经在挂机。现在要玩家**自己点「开始挂机」**才起算，也可以随时停。

---

## 一、规则

| 项目 | 规则 |
| :--- | :--- |
| 新角色 | 建好时**没在挂机**：打坐的真气、纹银，巡历的场次、精英锻材、装备与宝箱都不累计 |
| 开始挂机 | 从点下的那一刻起算，下线也照常累计，最多攒 24 小时（`docs/21`） |
| 停止挂机 | 先把已攒的收功一次领清（与「领取收益」相同：掉落、宝箱、江湖邸报、各处顺带领的封赏），再停；停着的那段之后开始也**不补** |
| 按挂机时长才有的 | 洪七公的食材采办、故人寻访的「闭关打听」线索，只算挂机着的时间 |
| 老角色 | 没有这个标记，一直在挂机，不受影响；演武（DEMO）开局同样一直在挂机 |
| 不受影响 | 襄阳值守的镜像代打、摆摊、结义镜像助战、劫镖追捕的镜像应战，照旧按各自规则进行 |

## 二、画面

- **修行页**：没在挂机时，状态写「尚未挂机」，「领取收益」的位置换成「开始挂机」；挂机时状态写「正在修行…」，旁边一个小按钮「停止挂机」。
- **巡历画面**：没在挂机时不打，上方写「未在挂机」，中间是说明和「开始挂机」按钮；开始后按 `docs/25` 每分钟一场演出来。
- 开始、停止各在修行日志记一条。

## 三、实现

- **存档**：`PlayerDTO.idleOff`（存在角色 `profile` 里，不改数据库表）。新角色由 `createNewGameCharacter` 带上；老角色没有这个字段，按一直在挂机处理。
- **规则**：`shared/player.ts` 的 `startIdle`：去掉标记，把打坐起算点 `lastSettleAt` 与巡历起算点 `trial.lastPatrolAt` 挪到此刻。
- **服务端**：`POST /api/v1/cultivate/idle`，body `{ on: boolean }`。开始返回空收益；停止走与 `/cultivate/settle` 相同的收功（`collectIdle`）再记标记。没在挂机时 `idleRewards` 不累计、`settlePatrol` 不推进，食材与线索的时长按 0 算。
- **前端**：`stores/cultivation.ts` 的 `setIdle`（联机走接口，本地试玩同一套规则），`CultivateConsole.vue` 与 `PatrolSkirmish.vue` 的按钮。
