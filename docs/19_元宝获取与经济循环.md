# 19 · 元宝获取与经济循环

> 口径：联机为准，本地试玩调用同一份规则（`shared/economy.ts`、`shared/gacha.ts`）。
> 本册取代 17 册「首日 300~500 元宝」的旧口径；抽卡概率以本册第四节为准，专题册已同步。

---

## 一、目标与原则

| 节点 | 免费元宝累计 | 体验 |
| :--- | :---: | :--- |
| 首日 | 约 1,200 | 够一次十连，首日就能见到结缘揭晓 |
| 第一周 | 约 2,000~2,500 | 第二次十连，或攒着冲保底 |
| 第一卷（约两个月，704 有效小时） | 约 1 万 | 约 100 抽，平均出 1~2 个神品，至少吃满一次 90 抽保底 |

1. **元宝只花在三处**：醉仙楼·结缘、故人重逢令、子时鬼市竞拍。**不卖真气、不卖挂机时间**，挂机进度不能用钱买（与 17 册「拒绝无脑逼氪」一致）。
2. **前多后匀**：一次性里程碑集中在前两章，持续产出平摊到每天，让回访有理由。
3. **服务端权威**：每笔增减都记流水；同一奖励只发一次，争议可查。
4. **充值暂不接入**：月卡、江湖令（01 册 §6.1）要接真实支付、实名与未成年人限额，单独立项。

---

## 二、一次性奖励（第一卷合计约 3,000）

奖励由存档状态推出：首通、突破、集齐等状态一旦成立就发放，已领的键记在 `player.ingotClaims`，不会重复。

| 来源 | 规则 | 第一卷合计 |
| :--- | :--- | ---: |
| 开局 | 新角色 300 | 300 |
| 江湖行历圆满 | 十阶行历全部领完 100 | 100 |
| 主线首通 16 个节点 | 普通节点 30；每章最后一个节点（1-3、2-3、3-4、4-3、5-3）100 | 830 |
| 历练首通 30 关 | 普通关 10；章末复战关（7、13、21、26、30）80 | 650 |
| 突破境界 | 第二重、第三重各 200 | 400 |
| 支线奇遇 13 段 | 首次了结 20 | 260 |
| 收集羁绊 3 套 | 全员入队 100 | 300 |
| 门派晋升 | 第 2~5 阶各 50（换门派不重复发） | 200 |

## 四、消耗与抽卡概率

| 用途 | 价格 |
| :--- | :--- |
| 醉仙楼·结缘 | 单抽 100，十连 950 |
| 故人重逢令 | 150，仅对错过的剧情送伙伴 |
| 子时鬼市竞拍 | 每次加价 50（联机版下一轮做） |

**结缘概率（2026-11-16 收紧）**

| 项目 | 旧值 | 现值 |
| :--- | :---: | :---: |
| 神品基础概率 | 1.5% | 0.8% |
| 绝品 | 8% | 6% |
| 上品 | 30% | 25% |
| 软保底 | 第 60 抽起每抽 +5% | 第 70 抽起每抽 +7% |
| 硬保底 | 第 80 抽 | 第 90 抽 |
| 含保底的综合神品出率 | 2.42%（约 41 抽一个） | 1.80%（约 56 抽一个） |

20 万抽统计：神品 1.80%（解析值 1.796%）、绝品 5.99%、上品 25.13%，最长神品间隔 81 抽。十连保底上品不变。

按第一卷约 100 抽计：平均出 1.8 个神品，最差也有 1 个（第 90 抽保底）。

## 五、服务端实现

| 内容 | 位置 |
| :--- | :--- |
| 元宝流水 `ingot_ledger`：每笔增减、余额、原因、`ref`；`ref` 非空时每人唯一 | `server/migrations/012_ingot_ledger.sql` |
| 结缘审计 `gacha_log`：每一抽的档位、条目、资质、是否保底 | 同上 |
| 里程碑在每次操作后统一结算，随存档写流水 | `server/src/game.ts` `writeAction` |
| 新接口 | `POST /market/gacha`、`/companions/awaken`、`/market/feast`、`/ftue/claim`、`/daily/claim`；`/story/reunion/:id` 新增 `ticket` |

同时补齐的联机玩法（原来只有本地试玩有）：

- 新角色与本地「新游戏」同一套开局：Lv.1、300 元宝、无伙伴、青钢长剑。新学的武功、新得的装备自动填进空槽。
- 伙伴形态、资质、信物与觉醒；好感上限随主线章节抬高（300 / 600 / 1000）。
- 十道绝味：在对应地图离线 30 分钟以上收功即可采到食材，每天给洪七公做一道，十道做齐他就入队；做过的菜同时算作丐帮百味考核已备好。
- 江湖行历的进度与领奖改由服务端校验。
