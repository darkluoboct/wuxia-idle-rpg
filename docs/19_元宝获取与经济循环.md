# 19 · 元宝获取与经济循环

> 口径：联机为准，本地试玩调用同一份规则（`shared/economy.ts`、`shared/gacha.ts`）。
> 本册取代 17 册「首日 300~500 元宝」的旧口径；抽卡概率以本册第四节为准，专题册已同步。

---

## 一、目标与原则

| 节点 | 免费元宝累计 | 体验 |
| :--- | :---: | :--- |
| 首日 | 约 1,200 | 够一次十连，首日就能见到结缘揭晓 |
| 第一周 | 约 2,000~2,500 | 第二次十连，或攒着冲保底 |
| 第一卷（约两个月，704 有效小时） | 约 1 万 | 约 100 抽，平均出 1~2 个神品，至少吃满一次 90 抽保底 |

1. **元宝只花在三处**：醉仙楼·结缘、故人重逢令、子时鬼市竞拍。侠客之间的买卖（第七节）只用纹银。**不卖真气、不卖挂机时间**，挂机进度不能用钱买（与 17 册「拒绝无脑逼氪」一致）。
2. **前多后匀**：一次性里程碑集中在前两章，持续产出平摊到每天，让回访有理由。
3. **服务端权威**：每笔增减都记流水；同一奖励只发一次，争议可查。
4. **充值暂不接入**：月卡、江湖令（01 册 §6.1）要接真实支付、实名与未成年人限额，单独立项。

## 六、子时鬼市压轴暗拍

全服每天竞拍同一件拍品，是元宝的主要去处之一。成交价七成回收，三成作红封分给当日活跃的侠客；不进任何个人的口袋。

| 规则 | 内容 |
| :--- | :--- |
| 场次 | 每个鬼市日一场：子时（23:00）开拍，次日 21:00 落槌；21:00~23:00 公示成交 |
| 出价 | 无人出价时按起拍价，此后每口在最高价上加 50；自己领先时不能再出 |
| 冻结与退还 | 出价时元宝立即扣下；被人压过，原数退还并实时推送提醒 |
| 防抢拍 | 落槌前 5 分钟内有人出价，落槌顺延到出价后 5 分钟 |
| 匿名 | 出价人显示为六十甲子代号（如「蒙面客·乙巳」），每场随机打乱；自己看到的是「你」 |
| 领取 | 落槌后由最高出价者在鬼市领取；领取时已从别处得到同一件，则原数退还元宝 |
| 已拥有 | 已拥有该拍品的侠客不能出价 |
| 红封 | 成交价的 30% 作红封池，分给**当日 21:00 前领过每日江湖事**的侠客；流拍没有红封 |

**红封怎么分**

| 情形 | 分法 |
| :--- | :--- |
| 持签人数不多 | 人头平分，向下取整，每人至多 30；分不完的回收 |
| 每份不足 10 元宝 | 改为抽签：中签人数 = 红封池 ÷ 10（向下取整），中签者平分红封池，每人 10~19 |
| 无人持签 | 全数回收 |

- **签的时点固定在 21:00**，不随落槌顺延变化：落槌时持签人数已经定死，谁先兑付算出来的份额都一样。
- **抽签次序**由本场的随机盐与角色编号散列决定，开拍时不可预知，落槌后人人可复核。
- **兑付**不用定时任务：落槌后侠客的下一次操作里自动到账，进鬼市看榜也会立刻兑付。流水原因 `auction-dividend`，`ref` 为 `auction-dividend:<场次>`，每场每人只入账一次。
- 起拍 180~360，红封池至少 54：最少也有 5 人中签；独自持签时拿满 30。

**拍品七日一轮**

| 拍品 | 品质 | 起拍 | 拍主 |
| :--- | :---: | ---: | :--- |
| 《凌波微步》 | 神品 | 320 | 鬼市压轴官拍 |
| 《九阴真经总纲》 | 神品 | 360 | 全真逆徒·匿名销赃 |
| 《碧海潮生曲》 | 神品 | 360 | 桃花岛哑仆 |
| 【岳武穆遗书】 | 神品 | 300 | 临安府库流出 |
| 《降龙·亢龙有悔》 | 神品 | 360 | 丐帮污衣叛徒 |
| 《打狗棒法》 | 绝品 | 200 | 君山流落长老 |
| 【东邪·碧玉箫】 | 绝品 | 180 | 桃花岛弃徒 |

《凌波微步》只在暗拍出现，其余拍品也能从结缘或副本获得，暗拍给了不想赌概率的侠客一条确定的路。

**实现**：`shared/ghostAuction.ts`（规则，含红封 `auctionDividend`、`settleAuctionTickets`）、`server/migrations/013_ghost_auction.sql`（场次与出价记录）、`014_auction_dividend.sql`（数持签人头的索引）、`GET / POST /market/auction`。同一场出价用事务锁串行；压过别人时在同一事务里锁住上一位领先者、退还元宝，提交后推送 `AUCTION_OUTBID`。本地试玩用同一份规则，只有你一位出价人。

## 七、子时鬼市蒙面摊位（纹银）

侠客之间的自由买卖。**只用纹银，不用元宝**：元宝日后要接充值，玩家之间用元宝交易等于给工作室开了变现通道。

| 规则 | 内容 |
| :--- | :--- |
| 可卖 | 草药（16 种）与武学残页。装备、武功、元宝都不能交易 |
| 门槛 | 摆摊与采买都要 Lv.10，挡住刚建的小号 |
| 上架 | 货物立刻从背包扣下，由鬼市代管；每摊一种货、1~99 份，挂 24 小时；每人至多 5 摊 |
| 限价 | 单价须在参考价的 50%~200% 之间：挡住小号贱卖输送，也挡住天价转移纹银 |
| 费用 | 摆摊费为标价总额的 2%（至少 1 两），上架时付、不退；成交后从卖家所得里抽 10%。两笔都是纹银回收 |
| 成交 | 可以只买一部分。买家付钱当场拿货；两人同时买同一摊，先锁到的成交，后到的按剩余数量重试 |
| 入账 | 卖得的纹银先记在摊位上，摊主的下一次操作前自动入账；摊主在线时会收到「卖出」提醒并立刻到账 |
| 收摊 | 卖完、到期或撤摊后，剩货退回背包；撤摊不退摆摊费 |
| 匿名 | 每个摊位各起一个六十甲子代号（「蒙面摊主·乙巳」），同一位摊主的几个摊互不相认；摊主不知道买家是谁 |

**参考价（两 / 份）**

| 草药稀有度 | 常见 | 少见 | 稀有 | 珍稀 | 传说 |
| :--- | ---: | ---: | ---: | ---: | ---: |
| 参考价 | 20 | 50 | 160 | 500 | 1,500 |

| 残页所属武功品质 | 凡品 | 良品 | 上品 | 绝品 | 神品 |
| :--- | ---: | ---: | ---: | ---: | ---: |
| 参考价 | 80 | 160 | 400 | 1,200 | 3,000 |

**鬼市散客摊**：每个鬼市日三摊，常见、少见、稀有草药各一种（5 / 3 / 1 份），按参考价上限出售，整摊买走，每人每摊每天一次。人少时也有货可买，同时给玩家摊位的价格封了顶；珍稀与传说草药只能靠采药或向别的侠客买。

**防倒卖**：限价带 + 一成抽成，使倒手至少亏掉一成；小号受 Lv.10 门槛限制；每笔成交写入 `stall_sales`（买卖双方、数量、单价、抽成），可事后复核。

**实现**：`shared/stalls.ts`（规则）、`server/migrations/016_ghost_stalls.sql`（`stall_listings`、`stall_sales`）、`GET / POST /market/stalls`（`list`、`buy`、`cancel`、`collect`）。买入只锁买家与摊位两行，不跨角色加锁；摊主结账在自己的事务里做，存档里的 `stallOpen` 记着还有几个摊没收，为零时不查库。本地试玩用同一份规则，可以摆摊、撤摊、等到期和买散客摊，只是没有别的侠客来买。
