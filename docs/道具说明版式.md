# 道具说明版式

在信件附件、背包、任务奖励和玩法掉落中点击道具，均在图标旁打开同一张道具卡。条目随游戏配置变化，阅读顺序固定。

| 位置 | 字段 | 显示规则 |
| --- | --- | --- |
| 卡头 | 原图、名称、品质 | 品质紧邻名称，同时显示游戏品名和品质色。纹银、元宝、真气按资源配置显示原图。 |
| 名称下方 | 类型、数量 | 类型从大类写到可辨认的子类，如「武器 · 匕首」「丹药 · 突破」。数量取点击那一格的数量。 |
| 正文第一段 | 基础属性 | 装备把一项属性与一个带单位的数值对应排列，如「攻击 +95」「暴击率 +15%」。影响全队时写明作用范围。 |
| 正文第二段 | 装备效果或用途 | 装备逐条列效果，依次交代触发条件、效果和持续时间。丹药列使用时机与单枚效果，材料列配方或参悟用途，货币列可支付的项目。 |
| 正文末尾 | 套装、来历 | 有套装时列套装名。有背景故事时以较弱的文字放在最后。 |
| 卡底 | 本次来源或所在位置、可用操作 | 附件和奖励显示当前来信、任务或关卡名。背包显示所在位置和穿戴状态，可比较的装备提供「同部位对比」。 |

品质名称沿用凡品、良品、上品、绝品、神品。没有对应配置的字段整段省略。小屏横版优先保留卡头和操作行，较长的效果列表在卡内滚动。

「随身物品」使用全宽横版网格，支持按装备、丹药、药材和残页筛选。每格显示图标、名称、数量，身上的装备另标「已穿戴」。点击格子打开道具浮窗，可在同一浮窗内查看同部位对比并穿戴。换装后回到原格，保留当前分类和滚动位置。

基础属性与装备效果中的数值统一用亮青色粗体。正负号、小数、千分位、百分号及紧随的计量单位随数值着色，如「+2,000」「25%」「1 回合」。同部位对比把两件装备的同名词条放在同一行，两列沿用相同的数值颜色。缺少该词条的一侧显示「—」。
