# 24 · 删除角色（已实装）

> 一个账号一位角色。删掉后账号仍登录着，可以马上新建一位侠客。

---

## 一、玩家怎么删

在「选择角色」里选中角色，点「删除角色」，**输入角色名、再输入账号密码**才能确认。删除接口每分钟最多试 5 次。

**以下情况不能删**，先了结再删，免得连累别人：

| 情况 | 提示 |
| :--- | :--- |
| 正在与人共修（已开始、未结束） | 正在与人共修，结束后才能删除 |
| 在今晚的鬼市暗拍里领先（元宝冻着） | 你在鬼市暗拍里领先，落槌后才能删除 |
| 在结义副本的候场队伍里 | 你还在结义队伍里，先离队再删除 |

删除成功后，本设备回到建角；同一账号在其他设备上的连接被断开，它们重连时也回到建角。

## 二、删掉什么、留下什么

| 随角色清掉 | 留档不删 |
| :--- | :--- |
| 修为、元宝、纹银、装备、武学、伙伴、配装 | 聊天记录（按聊天的 180 天留档，23 册） |
| 华山论剑、门派演武的报名，襄阳军功，摆着的摊位（货物不退） | 元宝流水（对账） |
| 未开始的共修邀约、留帖，结义镜像 | 结缘记录（概率争议复核） |
| 持有的真品神兵交还传功长老 | 江湖商行购买记录 |

## 三、30 天内可以恢复

- 删除前把角色整份转存（`deleted_players`）：角色行与装备、武学、伙伴、配装各行。保留 30 天，到期自动清掉。
- **恢复**在运营后台「玩家」页底部的「已删除的角色」里，运营起可操作，审计记下。用于误删或账号被盗删，**请先核实是本人**。
- 恢复的条件：账号此刻没有角色（新建了角色就不能再恢复）、名号没被别人占用。恢复后原角色 ID、装备、武学、伙伴回来；榜单、摊位、共修等随删除清掉的不回来。
- **名号保留**：30 天内，删掉的角色名只留给原账号，别的账号起不了这个名，防止冒名；原账号可以马上用回这个名字新建。

## 四、实现

- **接口**：`POST /api/v1/player/delete { nickname, password }`（`server/src/game.ts`）。转存、删除与恢复在 `server/src/deletePlayer.ts`；后台 `GET /api/admin/deleted-players?q=`、`POST /api/admin/deleted-players/:id/restore` 在 `server/src/adminOps.ts`。
- **数据**：`server/migrations/024_delete_player.sql`：建 `deleted_players`；聊天、元宝流水、结缘、商行购买四张留档表去掉对 `players` 的外键，角色删掉后记录还在。
- **前端**：`frontend/src/components/CharacterSelect.vue` 的删除确认；`frontend/src/stores/onlineGame.ts` 的 `deleteCharacter`；后台 `frontend/src/admin/DeletedPlayers.vue`。
