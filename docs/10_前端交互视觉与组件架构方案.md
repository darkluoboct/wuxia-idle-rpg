# 《金庸群侠：问道武林》前端交互视觉与组件架构设计方案

> **设计核心**：围绕**“简化美术（静态人物立绘） + 深度金庸文字表现 + 多人同服实时交互”**三大特征，前端不堆砌沉重的3D渲染，而是以**“古籍宣纸排版美学、呼吸感微动效、高可读性结构化战报流、低延迟房间态势感知”**打造高级的新国风文字武侠质感。

---

## 一、 视觉美学规范：【宣纸水墨 · 朱砂金泥】

纯文字占比高的游戏，**字体层级、底色护眼度与色彩语义**直接决定玩家的长期留存。系统内置两套视觉主题（支持手动切换，且进入【子时嘉兴鬼市】时自动平滑过渡至暗色主题）：

### 1.1 双主题色彩Token规范

| 语义角色 | 白昼主题【宣纸卷】（默认日常） | 子夜主题【玄墨卷】（鬼市/夜间护眼） | 适用场景说明 |
| :--- | :---: | :---: | :--- |
| **全局背景底色** | `#F4EFE6`（古宣米白，带极淡纸纹） | `#141619`（松烟深墨） | 页面主背景，久看不刺眼 |
| **卡片/面板容器** | `#EAE2D3`（熟宣暖灰） | `#1E2227`（乌金石色） | 人物框、装备栏、弹窗底板 |
| **边框与分割线** | `#D1C5B0`（檀木细线 `1px`） | `#323842`（寒铁暗线 `1px`） | 模拟线装古籍分栏线 |
| **正文主墨色** | `#262422`（徽墨浓黑） | `#E2DDD5`（月白宣色） | 挂机日志、剧情对白正文 |
| **次要注解色** | `#736B5E`（淡墨褐灰） | `#8C877E`（苍灰） | 时间戳、属性说明、未解锁置灰 |
| **朱砂印章红（核心强调）** | `#B83B2B` | `#D94E3B` | 绝技释放、突破按钮、叛师追杀报警、暴击数字 |
| **泥金/鎏金色（至尊荣耀）** | `#B58938` | `#E0B354` | 天下五绝头衔、全服唯一真品神兵、奇遇金光提示 |
| **竹青色（正气/增益）** | `#2E6F5E` | `#469E86` | 和平共修区标识、回血疗伤、轻功闪避成功 |

### 1.2 武学与器物品质五色阶
* **凡品（绿）**：`#4A7C59` | **良品（蓝）**：`#3B6E8C` | **上品（紫）**：`#7A4988` | **绝品（橙）**：`#C86D25` | **神品/唯一（赤红描金）**：`#B82929`（外框带微弱流光边框）

### 1.3 字体排版与微动效准则
* **标题/招式大字/侠客判词**：优先使用开源古风衬线体/楷体（如 `LXGW WenKai / 霞鹜文楷` 或 `Noto Serif SC / 思源宋体`），赋予浓厚的金庸书卷气。
* **滚动日志与数值面板**：正文行高严格保持 `1.75`，数值采用等宽对齐（`tabular-nums`），避免挂机加真气时数字跳动抖眼。
* **立绘微动效（零骨骼成本做出鲜活感）**：
  * 静态半身立绘通过 CSS/Canvas 实现 **3秒周期极轻微上下呼吸浮动**；
  * 打坐时立绘底部叠加一层半透明水墨真气涟漪；
  * 战斗出招时立绘向前快速冲刺 `16px` 回弹，受击时触发 `200ms` 红色闪白与横向震动，闪避时触发半透明残影横移。

## 四、 前端工程化架构设计（极易与自研后端对接）

为了方便您自己独立编写后端，前端将采用**高度解耦的数据驱动架构**，做到**“静态配置本地化、战斗播报结构化、接口Mock无缝切换”**。

### 4.1 推荐前端技术栈（轻快、跨端友好）
* **核心框架**：`Vue 3 (Composition API)` 或 `React 18` + `TypeScript` + `Vite`（若考虑后续一键打包微信小程序/App，也可直接选用 `Uni-app (Vue3+TS)`，界面纯 DOM/CSS 极易移植）。
* **样式方案**：`Tailwind CSS` + CSS Variables（一行代码切换【宣纸白昼】与【玄墨子夜】主题）。
* **状态管理**：`Pinia`（Vue）或 `Zustand`（React）。
* **动效引擎**：轻量级 `Framer Motion` 或原生 CSS Keyframes（用于战报逐条滑入、立绘震动、冲穴金光）。

### 4.2 结构化富文本渲染器（RichLogRenderer）
前端**绝不接收后端拼死的 HTML 字符串**（既费带宽又有 XSS 风险），而是由后端下发语义化事件对象，前端通过 `<RichLogRenderer>` 组件自动渲染出带颜色、带悬浮Tips的武侠文案！

例如，当战报中出现 `【降龙十八掌】` 或 `【玩家·西域毒皇】` 时，玩家在前端**点击战报里的蓝/橙色词条**，可直接弹出该武学的属性说明小卡片或该玩家的装备面板！

```typescript
// 前端富文本 Token 协议示例
export type RichSegment =
  | { type: 'text'; value: string }
  | { type: 'actor'; id: string; name: string; isAlly: boolean }
  | { type: 'skill'; skillId: string; name: string; tier: 'green'|'blue'|'purple'|'orange'|'red' }
  | { type: 'item'; itemId: string; name: string; isUniqueTrue?: boolean }
  | { type: 'damage'; amount: number; isCrit?: boolean; dmgType: 'phys'|'qi'|'poison'|'reflect' }
  | { type: 'status'; label: string; positive: boolean };
```

### 4.3 前端目录结构规划与“双模网络层（Mock / Real）”

```text
src/
├── assets/                 # 水墨底纹、人物半身立绘(WebP)、古风音效
├── config/                 # 静态只读策划表(与后端共享同一套JSON配置：门派、武学文本、章节描述)
├── network/
│   ├── httpClient.ts       # REST 请求封装(自动携带 JWT Token、统一错误吐司)
│   ├── wsClient.ts         # WebSocket 客户端(断线重连、心跳、频道事件分发)
│   ├── mockAdapter.ts      # 本地模拟服务端！后端未就绪的接口自动走本地Mock，写好一个切一个
│   └── types.ts            # 前后端完全对齐的 DTO 与 WS 消息类型定义
├── stores/
│   ├── playerStore.ts      # 角色六维、境界、银两、离线收益计算预览

│   ├── roomStore.ts        # 当前挂机地图信息、附近在线玩家列表、实时江湖事件流

│   ├── stage/              # 上半屏：打坐水墨舞台 & 3v3立绘对峙台
```
