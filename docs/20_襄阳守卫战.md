# 20 · 襄阳守卫战（已实装）

> 口径：联机为准，本地试玩调用同一份规则（`shared/xiangyang.ts`），以模拟守军代替其他侠客。
> 来源：01 册 §5.2「襄阳守卫战（全服协作 PVE）」、09 册 §5.2「襄阳城三门死守」。本册记录实际上线的做法，有出入处以本册为准。

---

## 一、一句话

每周三、周日 20:00 起半个时辰，蒙古大军分攻襄阳三处。全服侠客各守一门，每人五道军令，按打掉的敌军气血记战功；一门的战功攒够就击退一波，共八波。战后凭战功领元宝、铸造材料与功法残页。

## 二、开放与排期

| 项目 | 规则 |
| :--- | :--- |
| 开放 | 通关主线 2-3「终南金雁 · 重阳问道」（郭靖的剧情卡）；老角色不受限 |
| 开战 | 每周三、周日 20:00~20:30（北京时间），场次连号 |
| 平日 | 可以上城演练：任选城门与第 1~8 波，敌军与开战时相同，不耗军令、不记战功、不发奖励 |
| 入口 | 江湖 → 襄阳守城 |

## 三、三门

| 城门 | 敌军 | 架势 | 克制 | 特点 |
| :--- | :--- | :--- | :--- | :--- |
| 东门 · 铁骑冲阵 | 蒙古千夫长、铁骑；第八波怯薛万夫长 | 刚猛 | 太极 | 全是骑兵，背嵬枪法与破骑兵刃加伤 |
| 北门 · 云梯攻城 | 攻城百夫长、重甲步卒；第八波回回炮营统领 | 太极 | 奇门 | 重甲难破，撞城锤蓄力时要打断 |
| 水路粮道 · 水军夜袭 | 蒙古水军百户、水鬼；第八波水军都统 | 奇门 | 刚猛 | 水战、夜战，水性好的占便宜 |

每波一名首领、两名兵卒（一名与首领同架势，一名换架势）。第五波起首领第 3 回合蓄力（铁骑践踏 / 撞城锤 / 火船冲阵），第八波换作大将。

## 四、出战与战功

- **军令**：每人每场 5 道。第一次出战时选定城门，本场不能换门。
- **敌军强度**：按出战者自己的等级缩放（以历练首领的等级曲线为基准），第 1 波 0.75 倍，每波 +0.1，第 8 波 1.45 倍。强弱不同的侠客都能出力。
- **战功**：首领按 3 份、两名兵卒各 1 份，按打掉的气血比例折算，满额 50；打赢再加 5。输了也按打掉的气血记功。
- **波次**：一门的战功攒够「30 × 本门守军人数」就击退一波，多出的战功留给下一波；一份战功可以连破数波。八波全退为「大捷」，之后出战仍记战功、不再推进。人人五道军令都打满约可击退八波，有人输仗就打不满。
- **城头战报**：最近 20 次出战滚动播报，击退一波时标出。开战中每 15 秒刷新。

实测（演武配置，Lv.30 时历练刚好打不过第 30 关）：第 1 波剩血约八成，第 4 波约五成，第 8 波只剩个位数仍能险胜。

## 五、封赏

收兵后在「襄阳守城」页领赏，每场一次：

| 项目 | 规则 |
| :--- | :--- |
| 元宝 | 出战过即 20（记流水 `xiangyang:场次`） |
| 百炼玄铁 | 1 + ⌊本门击退波数 / 2⌋，本门战功前三再 +1 |
| 淬火石 | 1 + ⌊本门击退波数 / 4⌋ |
| 功法残页 | 1 + ⌊战功 / 100⌋，最多 4；本门战功前三再 +2。落在最近一次出战时装着的外功上，没装外功不发 |
| 真气 | 战功 × 等级 × 0.5 |
| 纹银 | 战功 × 4 |

名次按本门战功，并列同名次。真气按领赏时的等级计。

## 六、实现

- **规则**：`shared/xiangyang.ts`（排期、三门与波次敌军、战功、推进、封赏、本地模拟守军）。
- **联机**：`GET /api/v1/xiangyang` 返回本场战况、本人军令与战功、战报、待领封赏与上一场战果；`POST /api/v1/xiangyang` 的 `action` 为 `sortie`（`warId`、`gate`）、`drill`（`gate`、`wave`）、`claim`（`warId`）。出战的事务先锁角色、再锁城门行，波次推进不会被并发打乱。错误码：`XIANGYANG_CLOSED`、`XIANGYANG_WAR_CHANGED`、`XIANGYANG_GATE_FIXED`、`XIANGYANG_NO_ORDERS`、`XIANGYANG_NO_AWARD`、`XIANGYANG_INVALID_GATE`、`XIANGYANG_INVALID_WAVE`；未开放返回 `FEATURE_LOCKED`。
- **数据**：`server/migrations/017_xiangyang_defense.sql`：`xiangyang_gates`（每场每门的波次与战功）、`xiangyang_entries`（每人每场的城门、军令、战功、残页武学、是否已领）、`xiangyang_sorties`（战报）。
- **本地试玩**：每门二到五名模拟守军，各打五次，出战时刻与战功由场次与城门定死；自己的出战记进存档，城门波次按时间先后连同守军推出。
- **界面**：`frontend/src/components/XiangyangDefense.vue`。
