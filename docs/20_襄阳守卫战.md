# 20 · 襄阳守卫战（已实装）

> 口径：联机为准，本地试玩调用同一份规则（`shared/xiangyang.ts`），以模拟守军代替其他侠客。
> 来源：01 册 §5.2「襄阳守卫战（全服协作 PVE）」、09 册 §5.2「襄阳城三门死守」。本册记录实际上线的做法，有出入处以本册为准。

---

## 一、一句话

每周一场「襄阳之围」，蒙古大军分攻襄阳三处。全服侠客各守一门，按打掉的敌军气血记战功；一门的战功攒够就击退一波，共八波。军令随时间回复、可以攒，下线后由你的镜像值守出战。在线只影响打法，不决定能不能参与。收兵后凭战功领元宝、铸造材料与功法残页。

## 二、为什么这样排

这是挂机游戏，侠客不会在同一时段上线。第一版照 09 册定在周三、周日 20:00 开战半个时辰，错过那半小时就整场没有。现在改成：

- **整周都在打**：一场从周一 00:00 打到下周一 00:00（北京时间），一场接一场，没有空档。
- **军令可攒、不浪费**：每 8 小时回一道，最多攒三道。攒满后再回的那一道由值守镜像替你打出；收兵时把手上余下的也打完。一周只上线一次，打出的军令和天天在线的人一样多。
- **在线只换打法**：自己挑时机、换配装出战，演练摸清每波敌军；周三、周日 20:00 起擂鼓一个时辰，亲自出战战功加五成。
- **奖励不等人**：收兵后下一次收功顺带入账，不必专门来领。

## 三、开放与排期

| 项目 | 规则 |
| :--- | :--- |
| 开放 | 通关主线 2-3「终南金雁 · 重阳问道」（郭靖的剧情卡）；老角色不受限 |
| 场次 | 每周一场，周一 00:00 至下周一 00:00（北京时间），按周连号 |
| 擂鼓 | 每周三、周日 20:00~21:00：亲自出战战功 ×1.5（值守镜像不加） |
| 演练 | 随时可以上城演练：任选城门与第 1~8 波，敌军与实战相同，不耗军令、不记战功、不发奖励 |
| 入口 | 江湖 → 襄阳守城 |

## 四、三门

| 城门 | 敌军 | 架势 | 克制 | 特点 |
| :--- | :--- | :--- | :--- | :--- |
| 东门 · 铁骑冲阵 | 蒙古千夫长、铁骑；第八波怯薛万夫长 | 刚猛 | 太极 | 全是骑兵，背嵬枪法与破骑兵刃加伤 |
| 北门 · 云梯攻城 | 攻城百夫长、重甲步卒；第八波回回炮营统领 | 太极 | 奇门 | 重甲难破，撞城锤蓄力时要打断 |
| 水路粮道 · 水军夜袭 | 蒙古水军百户、水鬼；第八波水军都统 | 奇门 | 刚猛 | 水战、夜战，水性好的占便宜 |

每波一名首领、两名兵卒（一名与首领同架势，一名换架势）。第五波起首领第 3 回合蓄力（铁骑践踏 / 撞城锤 / 火船冲阵），第八波换作大将。

## 五、军令与值守

| 项目 | 规则 |
| :--- | :--- |
| 军令 | 开场每人三道；此后每 8 小时（周一 00:00 起的 08:00、16:00、00:00）回一道，最多攒三道，收兵那一刻不再回。一场最多打出 23 道 |
| 亲自出战 | 有军令就能出战，用掉一道 |
| 值守 | 第一次出战即值守那一门，也可以不出战直接「值守此门」。值守跨场保留，换门随时可改：本场还没出过战就立刻生效，否则从下一场起算 |
| 镜像 | 冻结你最近一次出战或值守时的境界、属性、配装与同行侠客（与华山论剑、门派演武同一套），不带丹药；页上可「按当前配装更新镜像」 |
| 代打 | 军令攒满三道后，每到回复时刻就由镜像替你出战一次（手上仍是三道）；收兵时把手上余下的军令全部打完。全程挂机也能打满 23 道 |
| 先后 | 代打按到期时刻先后逐一结算，再轮到亲自出战；城门推进的顺序与时间一致 |

本场第一次出战（亲自或代打）时定下本场城门，本场不能换。

## 六、战功与波次

- **敌军强度**：按出战者的等级缩放（以历练首领的等级曲线为基准），第 1 波 0.75 倍，每波 +0.1，第 8 波 1.45 倍。强弱不同的侠客都能出力。
- **战功**：首领按 3 份、两名兵卒各 1 份，按打掉的气血比例折算，满额 50；打赢再加 5。输了也按打掉的气血记功。擂鼓时亲自出战 ×1.5，四舍五入。
- **波次**：一门的战功攒够「140 × 本门守军人数」就击退一波，多出的战功留给下一波；一份战功可以连破数波。人人 23 道军令都打满、平均每道约 49 战功，约可击退八波，大约一天一波（与第一版「五道军令、每人每波 30」同一比例）。八波全退为「大捷」，之后出战仍记战功、不再推进。
- **城头战报**：最近 20 次出战滚动播报，标出值守代打、擂鼓与击退。

实测：演示档（Lv.32）与四维各 120 的 Lv.30 测试档，三门八波都能打满 55 战功，一人守一门打满 23 道可八波全退；弱一些的侠客打不满，就要靠同门一起守。

## 七、封赏

收兵后、所有值守代打结算完即论功，每场一次。下一次收功时顺带入账，也可在「襄阳守城」页先领：

| 项目 | 规则 |
| :--- | :--- |
| 元宝 | 出战过（含代打）即 40（记流水 `xiangyang:场次`）；每周一场，与第一版每周两场各 20 持平 |
| 百炼玄铁 | 2 + 本门击退波数，本门战功前三再 +2 |
| 淬火石 | 2 + ⌊本门击退波数 / 2⌋ |
| 功法残页 | 2 + ⌊战功 / 200⌋，最多 8；本门战功前三再 +4。落在最近一次出战（含代打，用镜像的配装）时装着的外功上，没装外功不发 |
| 真气 | 战功 × 等级 × 0.2 |
| 纹银 | 战功 × 2 |

名次按本门战功，并列同名次。真气按领赏时的等级计。

## 八、实现

- **规则**：`shared/xiangyang.ts`（排期与擂鼓、军令回复与值守代打的时刻、三门与波次敌军、战功、推进、封赏、本地模拟守军）；镜像在 `shared/mirror.ts`。
- **联机**：`GET /api/v1/xiangyang` 返回本场战况、擂鼓、本人城门与战功、军令、值守、战报、待领封赏与上一场战果；`POST /api/v1/xiangyang` 的 `action` 为 `sortie`（`warId`、`gate`）、`post`（`gate`）、`drill`（`gate`、`wave`）、`claim`（`warId`）。收功（`POST /cultivate/settle`）的结果里 `xiangyang` 列出顺带领到的封赏。错误码：`XIANGYANG_WAR_CHANGED`、`XIANGYANG_GATE_FIXED`、`XIANGYANG_NO_ORDERS`、`XIANGYANG_NO_AWARD`、`XIANGYANG_INVALID_GATE`、`XIANGYANG_INVALID_WAVE`、`XIANGYANG_INVALID_ACTION`；未开放返回 `FEATURE_LOCKED`。
- **值守结算**　后台在开服时和每分钟检查到期军令，按到期时刻、角色 ID 排序，每批最多六仗。同一人的收兵余令一起提交，批间释放襄阳事务锁。亲自出战和换防排在已到期的军令之后。看榜和收功遇到个人积压会唤醒后台。收功先发当下可领的收益，周末余令全部入账后封榜，下次收功或在守城页领周赏。迟到的值守战报在下次收功时补入邸报。
- **数据**：`server/migrations/017_xiangyang_defense.sql` 与 `018_xiangyang_posts_auction_proxy.sql`：`xiangyang_gates`（每场每门的波次与战功）、`xiangyang_entries`（每人每场的城门、出战与代打次数、战功、手上的军令、残页武学、是否已领）、`xiangyang_sorties`（战报，含代打与擂鼓标记）、`xiangyang_posts`（值守）。
- `026_xiangyang_settlement.sql` 记录最近已封榜的周次，并为个人值守战报建立索引。
- **本地试玩**：每门二到五名模拟守军，一周里各打 23 次，出战时刻、战功与是否值守由场次与城门定死；自己的出战、军令与值守记进存档，到期的代打在看榜、出战与收功时按时刻补打，城门波次按时间先后连同守军推出。
- **界面**：`frontend/src/components/XiangyangDefense.vue`。
