# 第一卷战斗特殊效果实施方案

**开发按战斗机制排期。** 太祖长拳、越女剑法这类武学用现有倍率、暴击和出招文案即可。多门武学共用一个规则时，配置各自的数值和适用条件。112 条武学以及后面的装备、羁绊、关卡清单用来查找接入机会。

共享引擎已结算穿透、回血、护盾、反伤、持续伤害、打断、追加外功、免死、复活和配装属性。主线、历练与少室山的出招路径调用同一段伤害计算。 [共享效果](../shared/battleEffects.ts) · [战斗入口](../shared/battle.ts)

## 词条接入办法

| 情况 | 处理 |
| --- | --- |
| 已有基础属性或只是招式演出 | 继续使用基础属性与战报文案。基础武学的差异可以来自威力、暴击、品阶和取得时点。 |
| 已有同类结算 | 在现有 `battleEffects`、装备属性或套装档位填参数。把同机制、同口径的条目放进同一批。 |
| 有明确玩法，但缺一个触发点 | 先接一个可玩的代表效果，在现有战斗循环里加所需判断。后续武学、装备和羁绊复用该触发点。 |
| 口径冲突或入口待建 | 留在清单里。选入某批时再确认数值、条件和取得方式，并同步玩家能看到的说明。 |

测试按规则覆盖触发、失效和边界。相同规则换数值时用参数化用例和现有配置校验，每批挑一个正常玩法入口验证实际结算和战报。代表用例已有足够差异时，可直接用同一规则接更多配置。

### 入选批次的数值决定

1. **先定本批的量纲。** 同机制的词条共用单位、计算位置和边界。用现有战斗数值作对照。
2. **解决本批口径冲突。** 天蚕金丝掌套、玄铁匕首按第 15 册，第 30 关宝甲按第 13 册神品口径。白驼灵蛇杖的择主与毒伤倍率随同批配置与说明核对。
3. **给无限循环和首领百分比伤害设可验收规则。** 连击、反击、致死吸血、击杀回血、复活与毒引爆需要各自次数或伤害上限。东邪西毒、白驼万蛇噬骨和跨套装叠加用弱配、推荐配装与高配分别试算。
4. **确认新规则与已做效果的组合。** 护盾保留按盾值扣减、白骨爪两倍损耗和实扣血，九阳与软猬甲、出手后治疗与重伤、南帝北丐与追加外功都做组合用例。

| 维度 | 判定条件 |

| 规则对照 | 同一敌人、同一随机序列，只换本批涉及的配置。按效果断言实际气血、盾值、怒气、状态、目标或触发次数。 |
