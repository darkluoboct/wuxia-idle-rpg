## 🚀 首期 Demo 研发落地建议（MVP 范围）

若准备进入代码开发阶段，建议第一期先实现以下最小闭环：
1. **核心数据表（JSON）**：导入《03》《04》《06》中的射雕前 3 章关卡、12 门基础至绝品武学、10 件经典装备与 6 位核心伙伴（柯镇恶、穆念慈、梅超风、郭靖、黄蓉、洪七公）。
2. **单屏四页签 UI 结构**：
   * **【修行（打坐）】**：展示主角立绘、境界冲穴进度条、滚动播放门派/散人离线吐纳文字日志；
   * **【江湖（历练）】**：章节节点推进、正邪支线选项弹窗、“1主角+2伙伴”动态文字战报演播室；
   * **【武库（阵容）】**：主角与左右翼伙伴立绘槽、“内·外·轻·绝”四槽武学装配与装备穿戴；
   * **【市井（客栈/门派）】**：拜师考核界面、醉仙楼请酒送礼与子时鬼市鉴宝。
