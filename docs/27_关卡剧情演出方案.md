# 关卡剧情演出方案（第一卷《射雕篇》）

> 要解决的问题：玩家觉得「只是一味地在打怪」，过一关不知道为什么来、为什么打、打完去哪。
>
> 结论：病根不是缺剧情，而是**写了的剧情没有摆到玩家眼前**，加上**主线和历练两条线各讲各的**。方案分三步：先把每一关做成「起 · 战 · 结」三段演出；再把 16 个主线节点和 30 关历练排成同一条故事线；最后按章补写文案。前两期只改前端和 `shared/` 里的文案数据，不改数值，也不动服务端。

---

## 一、现状：为什么玩起来只像在打怪

### 1. 主线写了剧情，但玩家看不到

- 16 个主线节点都有 `intro`（开场）和 `firstClear.text`（首通叙事），各 1～2 句（`shared/storyData.ts`）。
- 关卡卡片上**不显示 `intro`**。卡片只列推荐等级、架势克制、敌首、机制提示和奖励（`frontend/src/views/JianghuView.vue:158` 附近）。
- 点「拔剑闯关」时，`intro` 才被塞进江湖日志，同一时刻战斗回放就开始了（`frontend/src/stores/story.ts:295-312`）。玩家的眼睛在看战斗，这一句没人读。
- 首通叙事只是日志里的一行，再加一个只写着标签（如「荒山断魂」）的提示条（`story.ts:169-175`）。

### 2. 历练 30 关在游戏里一句剧情也没有

- 历练是升级的主路（docs/13：每一级都要过一关），玩家打得最多。
- `TrialStageConfig`（`shared/trialStages.ts:51`）只有标题、首领、机制提示和掉落，**没有任何叙事字段**。
- docs/13 给 30 关每一关都写了「对白」和「过关播报」，这些字没有接进游戏。

### 3. 两条线讲同一段故事，九个首领要打两遍

主线和历练各自从嘉兴讲到华山，互不相认。其中 9 个主线节点的首领、地点和历练关重复：

| 首领 | 主线节点 | 历练关 |

| 铜尸陈玄风 | 1-3 荒山夜哭 | 07 荒山绝杀 |
| 完颜康（比武招亲） | 2-1 比武招亲 | 09 中都擂台 |
| 参仙梁子翁（赵王府） | 2-2 赵王府夜宴 | 13 王府突围 |

按《江湖行历》现在的顺序，玩家大约 Lv.5 在主线 1-3 看到「陈玄风毙命」，Lv.7 又在历练第 07 关杀他一次。两边都自称是第一卷的结局：主线 5-3 写「《射雕》一卷，至此圆满」，历练 30 发「射雕·天下第一」称号。剧情一旦讲清楚，这种矛盾会更显眼，所以必须一起解决。

### 4. 两条线用的等级刻度也不同

主线的推荐等级还是旧的 75 级刻度（`STORY_ARCS` 写着 Lv.1~15 到 Lv.61~75，终章推荐 Lv.72）。历练已经按 30 级重算，卷一上限是「融会贯通」Lv.30（`shared/gameData.ts:30`）。把两条线排进同一条时间线以后，主线的推荐等级要跟着位置改。主线首领的数值也要另行核对，本方案不改数值。

### 现成可用的东西

- **序章** `PrologueStage.vue`：全屏场景图、卷轴、翻页、跳过、最后一页「拔剑」。这正是每关「起」该有的样子，目前只用在开头。
- **剧情卡** `FeatureStoryCard.vue`：人物立绘、分页对白、末页「前往」。可以直接改成「结」。
- **战报插句**：`addAdventureObjective`（`shared/storyData.ts:696`）已经在往战报开头和结尾插 `EFFECT` 事件。阵中对白用同样的办法插，不用改战斗逻辑。
- **素材**：docs/13 有 30 关的对白和过关播报；`storyData.ts` 有 16 个节点的开场和首通文字；场景图有嘉兴（暮、春）、大漠、终南、黑沼五张。

## 二、目标

每一关首通时，玩家都能回答三个问题：

1. **我为什么来这儿？** 上一关留下的线索把我引来。
2. **这一仗为了什么？** 对手是谁，和我有什么过节。
3. **打完以后呢？** 发生了什么，下一步去哪、找谁。

另有三条体验约束：

- 首通一定能看到剧情，**复战和挂机巡历一律不弹**。
- 每关阅读时间：历练不超过 30 秒，主线不超过 60 秒。随时可以跳过，看过的可以重温。
- 打输了重来，不重播入关剧情。

## 三、演出：一关一回，分「起 · 战 · 结」

```
 起 · 入关卷轴                战 · 阵中对白                结 · 回目结语
┌────────────────────┐   ┌────────────────────┐   ┌────────────────────┐
│ [场景图]            │   │ 战报照常播放         │   │ 第十回 · 荒山绝杀    │
│ 前情：九颗骷髅头……  │   │ 陈玄风：「贼婆娘瞎了 │   │ 柯镇恶毒菱破空……    │
│ [立绘] 柯镇恶：      │   │  眼，老子……」        │   │ ─ 获得 ─────────── │
│ 「山顶有人在吐纳。」 │   │ ……                  │   │ 横练铜甲·兵刃 等    │
│        ● ● ○       │   │ 柯镇恶：「罩门露了！ │   │ ─ 下回 ─────────── │
│ [跳过]      [继续]  │   │  用那柄匕首！」      │   │ 南下中都……          │
│ 末页按钮：  [拔剑]  │   │ 胜：「贼婆娘……」     │   │           [前往]    │
└────────────────────┘   └────────────────────┘   └────────────────────┘
```

### 起 · 入关卷轴（打之前）

- 首通前点「拔剑闯关」或「挑战」时，先放卷轴，末页按钮是「拔剑」，按下才真正开战。
- 第一页的第一句**接住上一回的「下回」**，这样关和关之间是连着的。
- 历练 1～2 页，主线 2～4 页，每页不超过 120 字。有说话人时显示立绘，否则是旁白。
- 从序章里抽出卷轴外观做成通用组件，序章自己也改用它。

### 战 · 阵中对白（打的时候）

- 往战报里插 3～5 句话：开场一句、首领狂怒或机制触发时一句、胜负各一句。
- 在前端开始回放前插入，联机战报一样能插，服务端不用改。
- 可以按条件换台词：队里有某个伙伴、某个家世、某个奇遇的选择。例如历练 07 的陈玄风，玩家在「荒山遗落的匕首」里救过梅超风的话，开场换一句。
- 有机制的关，台词就落在机制上。例如陈玄风第五回合露出罩门时，柯镇恶喊「用那柄匕首」，正好提示玩家这一关认「靖」字匕首。

### 结 · 回目结语（打完以后）

- 首通胜利后弹出，代替现在只有一个标签的提示条。依次是：结果叙事、获得了什么、「下回预告」一句，加一个「前往」按钮直接跳到下一关。
- 和玩法开放剧情卡（FeatureStoryCard）排队：先放结语，再放剧情卡。
- 章末那一关用整页卷轴，并给出下一章的预告。

### 关卡列表与重温

- 主线卡片补上 `intro`。没通关的显示「前情」一句，通关的显示「本回小结」一句，旁边有「重温」按钮。
- 第四期做「江湖回忆录」：按回目列出已经看过的剧情，可以从头读一遍。
- 设置里加「剧情演出：完整 / 只看关后 / 关闭」，放在 `interfacePrefs` 里。

## 四、故事线：两条线并成一条

### 原则

1. **主线和历练排进同一条时间线，共 46 回。** 主线是大事，历练是大事之间江湖路上的事。
2. **同一个首领遇两次，就是同一段故事的上下两幕。** 先打的上幕以对方败走、留手或脱困收场，后打的下幕才了结。一个人只死一次。
3. **谁做上幕、谁做下幕，先看原设计里已经埋下的依赖。** 没有依赖时，选改字少的那一边。

| 首领 | 上幕 | 下幕 | 依据 |
| :--- | :--- | :--- | :--- |
| 陈玄风 | 主线 1-3 | 历练 07 | 07 的罩门机制认 1-3 掉落的「靖」字匕首（`trialStages.ts:1078`）。docs/13 里 07 的台词「贼婆娘瞎了眼」，默认梅超风已在 1-3 失明 |
| 完颜康 | 历练 09 | 主线 2-1 | 等级顺序：09 在 Lv.9，2-1 在行历里排在拜师之后 |
| 梁子翁 | 主线 2-2 | 历练 13 | 13 的台词「还我二十年宝蛇心血」，要先经过 2-2 的药蛇抉择 |
| 裘千丈 | 主线 3-2 | 历练 16 | 两边原文都能用，16 的「面粉砖露馅、自报家门」更适合收尾 |
| 黄药师 | 主线 3-3 | 历练 21 | 21 是第三章章末大关 |
| 周伯通 | 主线 3-4 | 历练 20 | docs/13 里 20 的台词开口就叫「好兄弟」，默认已在 3-4 结拜 |
| 欧阳锋（压鬼岛） | 历练 23 | 主线 4-1 | 4-1 结尾扎筏离岛，岛上的戏必须在它之前 |
| 裘千仞 | 历练 26 | 主线 4-3 | 26 的过关播报是「遁入后山」，4-3 是峰顶决战、取《武穆遗书》 |
| 欧阳锋（华山） | 主线 5-3 | 历练 30 | 「射雕·天下第一」称号和襄阳立像在历练 30 发（`trialStages.ts:193-202`） |

### 先后顺序怎么保证

两条线现在各自推进，所以讲不出先后。时间线要靠门槛来保证，门槛分两类：

- **A 类，主线等历练**：主线节点要等时间线上紧挨在前面的那关历练首胜后才开，共 12 处（1-2、1-3、2-1、2-2、3-2、3-3、4-1、4-2、4-3、5-1、5-2、5-3）。这一类只会让主线晚开，不会卡住升级，可以先加。
- **B 类，历练等主线**：例如历练 05 要等主线 1-3。这一类会把升级挡在主线后面，如果主线首领的数值还在按旧的 75 级刻度，玩家可能卡关。所以**先核对主线数值，再加 B 类门槛**。没加之前，玩家把历练刷到前面会先看到后面的故事，这期间靠《江湖行历》带顺序。

老存档：已经通关的照常算通关，门槛只管还没打的关；进度已经超过门槛的直接放行。

### 第一章打磨：数值、战斗节奏、江湖气息、门派（2026-11-22）

目标是把第一章（序章到历练 07，再到拜师）做成完整的一段。判断标准由 `frontend/tests/chapterOne.ts` 的通关模拟给出。模拟让一个新角色按《江湖行历》与剧情时间线打下去：每 5 分钟收一次功，能升级就升级，巡历够了就挑战，并固定随机种子。四种家世各跑一遍，结果钉在 `frontend/tests/chapterOne.test.ts`。

**发现的问题**

- 历练 01～06 的首领一回合就倒，主角满血。历练 07 两回合倒，第五回合的罩门和柯镇恶那句台词根本打不到。
- 行历卡在「八卦炉烟」，四种家世都卡在这里，有两个原因：
  - 入门丹方要悟性 20，新角色这时只有 12～18。
  - 丹方要一味终南的药材，嘉兴采不到。
- 1-3 掉落的「靖」字匕首不会自动装上，因为兵刃格一开始就有青钢剑。历练 07 的罩门机制和入关文字都假定你拿着它。

**改了什么**

- **历练首领强度**：`shared/trialStages.ts` 的种子加了 `hpPercent`、`atkPercent`，第 01～13 关按模拟调过。
  - 首胜的真气、纹银仍按关卡等级的基准首领算（`trialFirstClearQi`、`trialRewardHp`），首领内力也按基准算（`trialBossMp`）。所以经济和内力对拼都不变。
- **罩门**：放宽为持对的兵刃使出的普通外功或绝技都算。致命的那一击本身也记作「刺中肚脐罩门」。

**调之前（全卷模拟）**

**玩家分三档**（模拟的 `kit` 参数）

- 懒：只穿自动装上的东西，伙伴靠入队时自动编进空位。
- 一般：新掉的装备按战力换上。
- 勤快：另外挑最强的两位伙伴、换威力最高的武功，等级卡住时拿多余真气参悟。

第一章三档差不多；到第五章勤快玩家的战力是懒玩家的 1.8 倍，一般玩家约 1.4～1.5 倍。

**改了什么**

- **伙伴自动编队**（`shared/player.ts` 的 `autoSeatCompanions`）：新入队的伙伴补进空着的左右翼，与新得的装备、武功自动装到空槽同一个规矩。只排这一回新入队的，玩家自己腾空的位置不会被补回。服务端在每次动作结算后统一处理，试玩用一个同步监听。原来不编队的新玩家会一直只带一位家人伙伴，第二章就撞墙。
- **历练 14～30**：按一般玩家调，首战 3～6 回合（机制打得出来），攻击最多到基准的 5 倍，免得没换装的玩家被秒。历练 21 黄药师是撑满 10 回合的关，血量提到 13 倍，一般玩家也要听满十回合箫声。历练 28～30 为懒玩家另降了一点。
- **主线 2-1～5-3**：有了 B 类门槛，主线打不过整卷就停住，懒玩家到第四章已 Lv.40 封顶。所以主线首领按懒玩家定：到场就能拿下，约 9 回合、余血两三成。推荐等级改为一般玩家打到这一回时的等级（2-1 Lv.8 … 5-3 Lv.38），江湖页各章等级段跟着改：第二章 Lv.7～12，第三章 Lv.12～27，第四章 Lv.28～34，第五章 Lv.35～40。联机原来沿用旧服数值的 2-2、3-3、4-3、5-3 也改为与试玩一致。
- **主线 1-3**：郭靖在 1-2 之后自动入队，1-3 变轻松了，首领攻击 260 → 280。
- **巡历画面**：小怪与精英改按关卡等级的基准首领折算，不跟着首战首领的强度走。
- **B 类门槛**（`shared/stageScripts.ts` 的 `trialGateBlock`）：14 关历练的首战要先打完时间线上紧挨着的主线节点（02←1-2、05←1-3、10←2-1、13←2-2、14←3-1、16←3-2、20←3-4、24←4-1、25←4-2、27←4-3、28←5-1、29←5-2、30←5-3，01←1-1 即序章）。和 A 类一样只拦新角色还没首胜的关；巡历不拦。历练页写明原因，并有「先去主线」按钮。服务端错误码 `TRIAL_GATED`。
