# 23 · 江湖传音与界面布局（已实装）

> 口径：联机为准。试玩模式没有别的侠客，世界、门派两个频道放几句江湖闲话，自己说的话只有自己看得到；附近与私聊要在联机版里用。

---

## 一、频道

| 频道 | 谁能看到 | 发言条件 | 间隔 |
| :--- | :--- | :--- | :--- |
| 世界 | 全服在线侠客 | 10 级起 | 10 秒一句 |
| 门派 | 同门在线弟子 | 已拜入门派 | 3 秒一句 |
| 附近 | 同在一张地图的在线侠客 | — | 2 秒一句 |
| 私聊 | 你和对方 | 对方没屏蔽你 | 1 秒一句 |

- 每句 1~80 字，去掉首尾空白、合并连续空白。被禁言（22 册）时四个频道都不能说。
- **留档**：每句话都存下来（`chat_messages`），留 180 天，每 6 小时清一次过期的。连上江湖时，世界、门派、附近各取回最近 50 句；换图、换门派时重取对应频道。
- **私聊不怕对方不在线**：对方上线后在私聊页签看到未读，点开会话即读；在线时收到私聊还会弹提示。
- **屏蔽**：点别人的名字可以私聊或屏蔽。被屏蔽的人，世界、门派、附近里他的话不再显示，私聊也发不过来（提示「对方不便收你的私聊」）。在私聊页签底部可以解除屏蔽。
- **屏蔽词**：运营后台维护，命中的字样换成同样长度的 ＊，不分大小写。
- **传闻**：兵器谱易主、叛门悬赏等江湖传闻写进世界频道，标「传闻」。

## 二、界面布局

原先聊天藏在右栏「附近」里的「同图聊天」，只有同图一个频道，要点两层才看得到。现在：

```
┌────────────── 顶栏：名号 · 主导航 · 纹银元宝 · 来信 · 角色 ──────────────┐
│ 左栏「人物卷」          │      中间「江湖舞台」      │ 右栏「江湖卷」        │
│  头像、等级、战力        │  修行 / 江湖 / 武库 /      │  江湖行历            │
│  当前队伍、装备武学伙伴   │  门派 / 市井               │  每日江湖事          │
│ ─────────────────────── │                            │  任务 · 活动 · 附近   │
│ 「江湖传音」             │                            │   （附近侠客与地图，  │
│  世界 · 门派 · 附近 · 私聊│                            │    卡片上有「私聊」） │
│  消息列表、输入框         │                            │                      │
└─────────────────────────┴────────────────────────────┴──────────────────────┘
```

- **江湖传音常驻左栏人物卷下**，占满余下的高度；四个页签上带未读数。左栏放不下太多句时，点右上角「展开」，变成浮在舞台左下的大窗，再点收起。
- **右栏「附近」**只放附近侠客与江湖地图；每位附近侠客的卡片多了「私聊」按钮，点了直接在传音里打开与他的会话。
- **窄屏（< 768px，直接打开游戏页时）**：顶栏多一个「江湖传音」按钮，私聊未读显示数字、频道有新话显示红点，点开是占大半屏的传音面板。游戏装在 16:9 画框里时始终按桌面布局缩放，用不到这一档。

## 三、运营后台

后台导航新增「聊天」：

- 按频道、按侠客查最近的话（每页 100 句，可往前翻）。不填侠客时只列世界、门派、附近；**私聊只在按侠客查时列出**，用于处理举报。玩家详情里有「聊天记录」直达。
- **删除**：客服起就能删，各端立刻撤掉（`CHAT_REMOVED`），留档标记已删，审计记下原话。
- **屏蔽词**：每行一个，1~20 字，最多 2000 个，整份替换；运营起可改，审计记下个数。上线前请把正式的屏蔽词表贴进来。

## 四、实现

- **规则**：`shared/chat.ts`（`CHAT_RULES`、频道名、`normalizeChat`、`maskBannedWords`）；协议在 `shared/protocol.ts`（`ChatSendDTO`、`ChatMessageDTO`、`ChatConversationDTO`、`ChatPrivateBoardDTO`，推送 `CHAT_MESSAGE`、`CHAT_REMOVED`、`CHAT_REJECTED`）。
- **服务端**：`server/src/chat.ts`。发言经 `/ws` 的 `CHAT_SEND { channel, content, to? }`（不写频道按附近处理），校验、查禁言与屏蔽、过屏蔽词、留档后按频道投递：世界给全服、门派给同门（`rooms.sendToSect`）、附近给同图、私聊给双方。HTTP：`GET /api/v1/chat?channel=WORLD|SECT|MAP`、`GET /api/v1/chat/private`（会话与屏蔽名单）、`GET /api/v1/chat/private/:peerId`、`POST /api/v1/chat/private/:peerId/read`、`POST /api/v1/chat/block`。后台接口在 `server/src/adminOps.ts`：`GET /api/admin/chat`、`POST /api/admin/chat/:id/hide`、`GET/POST /api/admin/chat/words`。
- **数据**：`server/migrations/023_chat.sql`：`chat_messages`、`chat_blocks`、`chat_banned_words`。
- **前端**：`frontend/src/stores/chat.ts`（频道、未读、私聊会话、屏蔽）、`frontend/src/components/ChatPanel.vue`（面板）、`frontend/src/GameShell.vue`（左栏与窄屏的摆放）；后台 `frontend/src/admin/ChatView.vue`。
