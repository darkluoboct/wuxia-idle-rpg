# 门派贡献兑换与师门日常

> 补 05 册里还没落地的两块：门派贡献的去处（师门宝库），以及挂机时按门派刷出的生活文字（师门日常）。
> 代码：`shared/sectDaily.ts`（差事文案与记功）、`shared/sectExchange.ts`（宝库货单与兑换），前端 `components/SectTreasury.vue`。

## 一、为什么做

上线前的门派贡献只进不出：入门、请安、晋升、藏经阁值守、悬赏结案都在加，门派页也显示数字，但整个游戏没有一处消耗它。
挂机本身也和门派无关：拜入全真和拜入白驼，挂机日志一模一样。

这一期把两件事连起来：**挂机替师门办差事 → 记门派贡献 → 到师门宝库换东西**。

## 二、师门日常（差事）

| 规则 | 取值 |
|---|---|
| 攒差事的条件 | 已拜师，且在挂机（停止挂机的时段不算） |
| 每件差事 | 挂机满一个时辰（两小时） |
| 一次收功最多记 | 12 件（挂机本身最多攒 24 小时） |
| 每件记的贡献 | 30～50，按文案定；佩饰的贡献加成（如归云庄太湖水令 +20%）照算 |
| 记功时机 | 收功（领取收益、停止挂机）时；不满一个时辰的零头留到下次 |
| 入门、出师、叛师 | 没记的零头和师门日常都清空 |

- **文案**：七个门派各 10～11 条，共 76 条，每条不超过 60 字。每条有地点，有的只在特定时辰发生（早课在寅卯、喂蛇在亥子丑），有的到第 3、4 阶才轮得到（带新弟子、收服水寨）。
- **挑选**：从收功那一刻往回，每两小时一件，按那件事发生的时辰和当前阶位挑；最近办过的六件先不重复，相邻两件不会是同一件。测试保证每派、每阶、每个时辰至少有两条可挑。
- **呈现**：
  - 日志：最上面一行「师门差事 · 替师门办了 N 件差事，门派贡献 +X」，下面是最近三件的文案，形如【申时·试剑亭】你随哑仆在试剑亭对拆……
  - 江湖邸报的「门派」一栏：差事件数、贡献，和最近一件的文案。
  - 门派页「师门宝库」左栏「师门日常」：最近六件，以及「再挂 X 分，办下一件差事」或「已攒下 N 件，收功时记功」。
- **和原著、剧情的勾连**：江南武馆门口来了想学武的瘦孩子（序章被拒之门外的你自己）；全真后山古墓传来琴声；桃花岛岩洞里要跟你打赌的老先生；铁掌帮深夜上山的金国人；一灯居渔樵耕读四位师兄。

## 三、师门宝库

每样东西每周限兑几份，与门派演武同一周（周六 20:00 补货）。有的要升到某一阶才换得到。离开师门贡献清零，宝库里的东西是给留在师门里的人的。

**各派都有**：

| 东西 | 贡献 | 每周 | 阶位 |
|---|---|---|---|
| 玄门·聚气通脉丹 | 180 | 3 | 1 |
| 天山·冰魄护心丹 | 500 | 1 | 2 |
| 纯阳·通脉破障丹 | 800 | 1 | 3 |
| 本门武学残页（已学会的本门传承武学，每门一份货） | 绿 10 / 蓝 20 / 紫 40 / 橙 80 / 红 150 | 每门 10 | 1 |

**各派特产**（物品的出处原本就写着这些门派）：

**收支估算**（不算请安以外的来源）：

- 一直挂机：每天 12 件差事约 480，加请安 60，一周约 3,800。
- 每天收功两三次、挂 16 小时：一周约 2,600。
- 一阶弟子每周能花的大约 1,100～1,500，会有结余；三阶以后加上冰魄、破障和更多残页，每周货单约 3,000 以上，需要取舍。

## 四、接口与存档

- `POST /api/v1/sect`，`{ action: 'exchange', sectId, goodId, count }` → `{ action: 'exchange', goodId, count, price }`；不满足条件时 409 `SECT_EXCHANGE_UNAVAILABLE`，带中文原因。
- 收功结果 `IdleGain.sectChores = { count, contrib, entries }`。
- 角色档案新增 `sectChores = { ms, recent }` 和 `sectExchange = { week, bought }`，存在 `players.profile` 里，不需要数据库迁移。
- 规则在 `shared/` 里，服务端和试玩共用；结算打坐（`creditIdle` / `settleMockIdle`）时攒时长，收功（`collectIdle` / `settleLocally`）时记功。
