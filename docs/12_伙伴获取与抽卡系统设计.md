# 《金庸群侠：问道武林》伙伴获取、进阶与客栈抽卡设计（草案）

> **状态**：草案，待评审。依据 2026-11-11 的讨论结论整理。
> **适用范围**：第一卷《射雕》起；对第 03 册 §4 的伙伴获取途径做细化与改写。

---

## 一、设计原则

1. **剧情送的伙伴最多是中等强度**（紫品），保证主线永远有人陪、永远不会被卡死。
2. **好感度刷的伙伴可达橙品，但偏低资质**；靠银子与时间换来，不赶超付费线。
3. **抽卡负责高端**：红品形态、橙品高资质、进阶信物。
4. **每位伙伴都有免费获得的路**；付费只缩短时间或提供更高上限，不卖独占。
5. **抽卡必须概率公示、有保底**；真实结算由服务端权威完成，前端 Demo 仅模拟。

---

## 二、品质与资质

品质沿用五阶：绿 / 蓝 / 紫 / 橙 / 红。**同一品质内再分资质**，用于拉开"同为橙品却强弱不同"的差距。

| 资质 | 适用 | 属性系数（作用于 baseHp / baseAtk） |
| :---: | :--- | :---: |
| 下 | 橙品，好感线产出 | ×0.88 |
| 中 | 橙品，抽卡产出（常规） | ×1.00 |
| 上 | 橙品，抽卡产出（稀有） | ×1.12 |

紫品及以下不分资质（系数恒为 ×1.00）。红品不分资质，但数值本身高于橙品上限。

## 三、伙伴矩阵

**一位伙伴最多有两个形态**：基础形态（免费线可得）与觉醒形态（需信物进阶）。

| 伙伴 | 来路 | 基础形态 | 觉醒形态 | 说明 |
| :--- | :---: | :---: | :---: | :--- |
| 柯镇恶 | 剧情送 | 蓝 | — | 1-2 烟雨楼结识后自动入队 |
| 穆念慈 | 剧情送 | 紫 | — | 2-1 比武招亲入队 |
| 梅超风 | 剧情送 | 紫 | — | 选择救治（荒山支线）后于 3-2 归云庄入队；选夺经则触发"重逢"补救 |
| 郭靖·少年 | 剧情送 | 紫 | 橙（侠之大者） | 1-2 结识后自动入队；成熟形态为橙品 |
| 黄蓉·少年 | 剧情送 | 紫 | 橙（桃花仙子） | 叫花鸡支线结缘后入队 |
| 周伯通 | 好感线 | 橙·下 | 红 | 3-4 结拜后结识，好感≥100入队 |
| 洪七公 | 好感线 | 橙·下 | 红 | 3-1 论掌后结识；完成"十道绝味"烹饪支线后可编入 |
| 黄药师 | 好感线 | 橙·下 | 红 | 3-3 桃花三试后结识 |
| 欧阳锋 | 好感线 | 橙·下 | 红 | 救下欧阳克结识，或 5-3 击败后重逢 |

> 抽卡直接抽到**尚未拥有**的好感线伙伴时，直接以**觉醒红形态**入队（等于跳过免费线）。抽到**已拥有**的，转为对应**伙伴信物**。

## 四、进阶与信物

- **伙伴信物**：每位伙伴各有一种，用于进阶或提升星级。获取：抽卡重复转化、重逢令附赠少量。
- **进阶条件**：好感 ≥ 600（生死之交）+ 消耗信物 × N（郭靖/黄蓉 → 橙：N=30；好感线伙伴 → 红：N=60，参数待评审）。
- 进阶后原基础形态的传功技能保留；觉醒形态额外追加协战技。

## 五、获取路线

### 5.1 剧情送
主线节点首通或支线抉择时，直接 `met = true` 且 `recruited = true`，好感记初值 100。

3. 好感 ≥600 触发"倾囊传功"，≥ 进阶门槛后可用信物觉醒。

## 六、好感与送礼限制

防止"囤银子绕过剧情"，叠加两层限制：

1. **每日次数**（以子时刷新）：每位伙伴 **清茶 ≤ 3 次 / 爱物 ≤ 1 次**。
2. **进度封顶**：好感上限随主线推进抬高。

| 已通关章节 | 好感上限 |
| :---: | :---: |
| 第 1 章前 | 300 |
| 通关第 3 章 | 600 |
| 通关第 5 章 | 1000 |

触顶后送礼不再增加好感，界面提示"此情已满，待江湖历练更深"。

## 七、客栈抽卡（"醉仙楼·结缘"）

入口位于 **市井 → 醉仙客栈**。

### 7.1 价格
- 单抽 **100 元宝**；十连 **950 元宝**。

### 7.2 产出与概率（公示值）

| 档位 | 概率 | 内容 |
| :---: | :---: | :--- |
| 红 | 1.5% | 红品伙伴（觉醒形态）/ 红品武学残页 / 神品装备 |
| 橙 | 8.0% | 橙品伙伴（资质：上 25% / 中 75%）/ 橙品武学、装备 / 进阶信物×10 |
| 紫 | 30.0% | 紫品武学残页、装备 / 进阶信物×3 |
| 蓝及以下 | 60.5% | 九花玉露丸、蓝品装备、少量纹银与真气 |

> 奖池是**混合池**：伙伴不是唯一产出，避免奖池过薄。

### 7.3 保底（随机，不定向）
- **硬保底**：第 80 抽必出红品；
- **软保底**：第 60 抽起，红品概率每抽 **+5%** 递增，至 80 抽封顶；
- 出红后保底计数清零；
- **十连保底**：十连至少一个紫品及以上。

### 7.4 重复转化
抽到已拥有的伙伴 → 转为对应**伙伴信物**（数量按档位：橙 20、红 40，待评审）。

### 7.5 公示页（必须）
抽卡界面常驻"概率说明"入口，列出：各档概率、保底规则、各档具体内容清单、资质分布。

## 八、重逢令（补救）

**场景**：玩家错过了剧情送或好感线的伙伴（例如荒山选夺经导致梅超风未入队）。

- **免费线**：触发"故人重逢"支线，每位被错过的伙伴 2~3 步（回到旧地 → 送礼 → 一场战斗），需达成对应章节与好感门槛。
- **付费线**：客栈出售"**故人重逢令**"，固定价格 **150 元宝**（待评审），使用后直接触发重逢并入队。
- 重逢令**不随机**；仅对紫品及以下的剧情送伙伴有效。好感线伙伴不适用（可走抽卡或养成）。

## 十、合规与服务端权威

1. **概率公示**：见 §7.5。
2. **未成年人保护**：接入真实支付后需实名认证与消费限额；Demo 阶段元宝仅为游戏内数字，数据结构预留 `age_verified`、`daily_spend` 字段。
3. **服务端权威**：真实环境中抽卡结果、保底计数、信物余额均由服务端维护，客户端仅展示。前端 Demo 中的 `mockEngine` 负责模拟该契约。
4. **审计日志**：每次抽卡写入 `gacha_log(user_id, pool_id, pull_no, result, rng_seed, ts)`，便于争议复核。

## 十六、以时间换取的免费路线（P2，已完成）

原则：免费线拼的是**天数**而不是单日强度——每个来源都有每日上限（以子时刷新），离线挂机也计入；付费只是跳过等待，价格固定、不随进度打折。

### 16.1 本地存档

- 进度写入浏览器 localStorage，带结构版本号；版本不符的旧档被忽略。读档时逐项合并默认值：旧档缺的新字段自动补齐，已删除的伙伴自动丢弃。
- 启动时若有存档，开局界面出现「继续江湖」（显示模式、等级、主线进度、存档时间），可删除存档；页头新增「存档并返回开局」。
- **关闭方式**：`.env.local` 中设置 `VITE_LOCAL_SAVE=false`，不读不写。接入服务端存档后即可关闭，`snapshot / applySave` 可直接作为上传 / 下发格式复用。
